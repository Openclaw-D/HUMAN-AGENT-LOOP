# Takeoff 核心最高产品基线

**版本：TAKEOFF-FA-1.0.0｜状态：用户要求固定的当前设计基线｜日期：2026-09-20**

## 1. 权威范围

本文是本轮**产品范围、业务终点、前端结构和验收方向**的最高依据。它落实用户最后明确接受的收敛，不是另一次方案探索。

同一产品问题的优先级为：**用户后续明确决定 > 本文 > 本包专项文件 > 与本轮兼容的现行仓库说明 > 历史任务、旧原型和旧图片**。

“最高”只指产品决策，不能覆盖适用法律、真实业务授权、访问控制、凭据保护、资金操作权限和运行环境安全。现有API契约作为实施约束保留；与新产品终点不匹配时，做明确的最小版本增量，不能静默改变其旧语义。

## 2. 唯一目标与终点

为中国大陆商业融资租赁的小微制造业新客户，完成**首次售后回租需求的准入与客户授信预评估**。

主对象是客户：`customerId` 绑定同一企业法律主体。四字简称只是展示名，不能代替ID，也不要求企业全称永不更名。一轮首次评估可以有多份材料、多次分析和多个方案修订，但不是多笔提款。

本轮终点：**有权人员确认预评估结论**，记录建议金额、建议期限、参考价格及其口径、条件、主要依据和必要的后续正式办理要求。

预评估确认 ≠ 正式授信批准 ≠ 额度激活 ≠ 可提款 ≠ 放款许可。完成本页不得自动创建或激活正式额度、预占额度、发起融资支用或支付。

## 3. 必做范围

- 一个横屏桌面主界面：顶部客户与方案摘要；左侧约80%的二十格看板；右侧约20%的六助手与操作区。两主体区向下铺满剩余空间。
- 横向五列固定为：**商机、政策、信审、商务、资产**。纵向四行固定为：**输入、智能、人工、完成**。行列标题只放两字与小图标。
- 每格可查看进度、卡点、责任人、所需材料和允许动作。分析与人工核验可以围绕已具备条件的事项部分并行。
- 一次上传、可追溯原件、事实与冲突识别、五领域协作、方案修订、补证重算、人工确认、记录与恢复。
- 五个专业助手：业务、政策、信审、商务、资产；一个全局助手：见微。共用一个工作区，不是六个窗口。
- 流程、记录、材料、待办只做入口，详情按需展开；不在主页面下方平铺示意卡。

## 4. 本轮明确不做

不做多次提款、老客户续作、复贷、租金计划、租后管理、催收、合同结清、合作历程、新客户目录重建、项目列表；不做地图、3D、视频场景、手柄、手机端或游戏化。

不做一套新的通用工作流平台，不做二十个独立Agent或二十套后台，不为展示能力增加常驻自动对话。

可以保留兼容旧数据所需的代码，但从本轮默认页面与默认运行路径中移除无关功能。保留底层代码不意味着把旧功能列入本轮交付。

## 5. 必须替代的旧设计

| 旧设计/说法 | 本轮唯一口径 |
|---|---|
| 历史“不以表格为主界面” | 当前以固定二十格矩阵为唯一主工作面，不是通用数据表编辑器 |
| 以Project为唯一主工作对象 | 客户是主对象；评估ID只是本次首次评估的工作范围 |
| 从商机一直办理到租后结清 | 只到人工确认首次回租准入预评估结论 |
| 商务完成以后资产才可以开始 | **撤销此规则。资产是准入时的真实性、权属与价值核验，可与信审等并行** |
| 输入整行结束才能开始智能，智能整行结束才能人工 | 只对同一项工作的实际前置条件设门，不锁死整行 |
| 顶部客户全生命周期完成率 | 本轮不显示此指标 |
| 顶部已用/可用额度及红绿使用率圆环 | 本轮不发生用信，移除；显示申请与建议方案 |
| 左下角合作历程、悬浮效果示例、详情弹窗示例、流程小图 | 全部从主页面撤下，空间还给看板与助手 |
| 材料越多，额度必涨、期限必长、价格必低 | 只依据有价值的新证据更新；可增、可减、冻结或不支持 |
| 绿色圆表示融资批准 | 绿色只表示该格工作完成，结论另行表达 |
| 结束按钮关闭客户或结清资产 | 结束本次评估，不关闭客户档案 |

## 6. 不得妥协的业务与证据纪律

模型输出是候选，正式权威属于有权人员。不可豁免规则不能由聊天、通用确认或前端按钮绕过。

未知不是零；技术失败不是客户高风险；冻结不等于拒绝；工作完成不等于正面结论；历史被推翻不能静默改写历史。

金额、期限、价格、条件绑定同一方案版本。新证据只重新处理受影响部分，但跨领域影响不能遗漏。

首次评估可以投入较多资源，但围绕关键风险有上限、有去重、有停止条件。不无限追求最高额度，不自动把产品上限批准给客户，不伪造贝叶斯概率或违约率。

## 7. 视觉与点选原则

浅浅的暖黄色牛皮纸质感；黑、灰、红、绿、黄为唯一有色体系；白色允许用于空圆、留白和冰霜。禁止蓝、紫、青等额外配色。

白圆=未完成进展；浅黄扇区=25%展示档位的进展；右上开始顺时针；全绿=工作完成。冻结用白色霜边与灰黑锁形文字，不用蓝色、不挡内容、不使补证操作失效。

悬浮高亮同行同列；点击打开真实事项；复杂证据可放大后还原。不要再把这些交互作为独立展示卡。

## 8. 变更门槛

本版默认按稳定基线实施，不每轮重新讨论布局、颜色、主对象和范围。排版细调、可访问性、缺陷修复、字段映射等不改变业务含义的调整可做并记录。

需要改变主对象、五列四行、人工权威、产品终点、颜色范围或扩展业务时，必须先列出：实际障碍、最小变更、代价、替代办法，由用户明确决定。技术实现困难不能成为擅自恢复旧方案的理由。

未确定的机构政策与实际数值通过配置或待确认状态处理；不能为了完整演示编造生产规则。本基线稳定不等于未知事项已经被证实。
