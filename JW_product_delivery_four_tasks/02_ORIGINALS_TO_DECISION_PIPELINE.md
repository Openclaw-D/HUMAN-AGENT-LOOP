# 任务二｜把原始材料真正送入同一条证据、预审和人工决定链

你是本地 ZCode 中 JW 的输入处理与执行负责人。目标是消除“解析留在 Connectors，审批脚本另造数据”的断链：客户在页面上传的原件，经过持久处理与四域核验，必须成为 A 中实际可复核的决定依据。连续完成规划、实现、服务级测试和页面联调。

## 1. 所有权与基线

负责 Back/B/**、Back/C/**、Back/Connectors/**、各自依赖与默认测试入口，文档放 docs/product-delivery/goal-02/。不改 A/共享契约、Edge、Front、D；向 01/03 提交具体接口需求并完成联合消费，不能把必需桥接长期 skipped 后宣称闭环。

读取本地规则和最新源码，确认主服务是否真的启动处理驱动。保留有效去重、缓存和选择性重算，不按历史报告重复重写。无自动 Git 写操作、真实密钥读取、付费或外发授权；一个主 AI 上下文，测试资源与其他路隔离。

## 2. 解耦边界

将解析器、模型执行、业务评估、渠道发送分别通过少量明确接口接到现有调度器；接口要能换实现，不创建新平台。

解析器只负责原件→观测/结构化行/来源定位，不决定授信；C 的租赁业务模块负责口径、四域及规则；B 负责运行、租约、重试、预算和恢复，不硬编码租赁审批；Connectors 负责接入、字节与处理状态，不拥有第二套正式决定。

字段映射、材料种类和专业域分工属于业务配置/模块；传输、解析和队列机制不因出现新的租赁字段而重写。替代适配器仍经过相同身份、来源与失败契约，不能任意写业务状态。

## 3. 打通真实的数据顺序

浏览器上传→受控字节落地和元数据校验→A 登记权威材料及版本→持久处理任务→解析/观测→按当前授权提取必要内容→A 固定执行输入→B/C 执行→提交真实输出与回执→相关检查/候选更新→页面展示。

原始字节与数据库不在一个原子事务时，设计 upload/finalize/receipt 的幂等和清理/补偿；不能一边显示上传完成，一边永久丢失任务。A ID 与 Connector ID 有持久映射，重试保持逻辑动作标识，不把网络未知改成确定未发生。各段状态、失败原因、等待谁和下一动作可被 03 查询。

规则/Gate/分析结果来自真实执行产物并绑定快照，不允许桥接器为满足 A 结构直接提交固定 CLEAR 或 completed。没有模型/渠道授权时，可使用明确标记的确定性业务处理与页面人工复核完成本地流程；不得伪称模型理解或外部消息已送达。真实提供方能力另列验收。

## 4. 收敛格式范围，但把客户常用原件办下来

与 04 固定一个覆盖执照、流水、账表、购机合同和设备证据的合成原件包，并明确每种材料自动/人工处理边界。

本轮必需：可靠 CSV/TSV、XLSX（固定合理表结构）、TXT、可提取文本的 PDF；ZIP 安全解包；JPG/PNG/扫描 PDF 可安全接收和预览。扫描识别有获准提供方则接入并单列评测；没有则走“原件可见、来源可选、人工录入/校正、获准复核”的产品入口，不交给开发者预填 JSON。

先查可复用的现有库再设计解析器；新增依赖记录必要性、版本、许可证与代价。CSV 引号/逗号/换行、金额千分位与负号、非法日期、编码、重复表头/合计行、Excel 日期与缺失公式缓存等必须正确处理或明确拒绝，不能错列/错金额后仍成功。未知币种/单位不猜，坏行不能静默参与完整合计。

原件不覆盖；人工更正追加修订、定位与理由；更正事实不等于人工核验完成。上传全部入账不等于经营收入，材料数量不等于独立证明，模型/原件中的指令不得进入系统命令通道。解压有路径穿越、展开大小、层数和文件数限制；大文件传输/解析不能占满交互资源。

## 5. 预审、问题与恢复

复用有效材料处理结果，但缓存键必须包含会改变结果的主体/期间/单位等元数据、解析器/模型/规则版本与权限范围，而不是只看文件哈希。根据证据依赖选择性重算；不能因复用旧结果漏掉新冲突。

问题给出对象、依据、目的、目标回答者、受众与预期证据；不同客户角色可并行，同一公共会话受控排队。未批准自动发送策略默认只建议。获准发送走服务端授权和幂等回执；Unknown 先对账，不换 ID 盲发。

本地页面内问答作为独立受控渠道可以完整运行，不依赖未开通的企业微信外发。回答、材料到位、事实核实三者分开；会后补证继续，不重问已回答问题；暂停/重启保留真实状态、来源和执行版本。

## 6. 阶段与验收

B1：先打通一个原始文件上传到 A 材料/解析结果的主入口，补齐跨服务 ID、失败与进度；修默认测试命令漏挂/损坏。
B2：处理上述原件范围，完成人工更正/复核所需后端；联通真实四域输出到 A 的运行和 Gate/依据引用。
B3：接通问题、补证、去重、恢复和有限负载优化，在 03 页面复验。每阶段独立变更边界，不交大量无人调用模块。

必须测：引号金额反例、非法日期、坏行合计、XLSX/text-PDF 原件、扫描人工路线、同字节不同元数据、压缩异常、错主体/设备/期间、重复上传、A 提交后断网、进程被终止后恢复、旧结果晚到、补证选择性重算和暂停。

集成验收由页面实际选文件启动，不向测试提供预填事实、Gate 或分析终态。通过改动原件里的金额/编号使结果随之变化，并用隐藏在测试端的期望值校验。支持范围内不能靠永久手工操作代替承诺的自动解析。

同输入比较处理时长、调用次数、队列等待与内存，同时检查事实正确和风险遗漏。交付 DESIGN.md、支持格式与边界、TEST_RESULTS.md、HANDOFF.md及可复现实物。没连进 A 或没被页面调用的能力只记模块完成。
