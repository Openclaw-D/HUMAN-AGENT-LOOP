# JW｜原件到人工决定：四路产品交付指令

## 共同完成标准

普通客户和业务人员，在约定的一次安装与管理员初始化之后，能通过正常页面，从一个新客户和一批原始材料开始，完成邀请、提交、处理、补证、核验、方案查看、有权人类决定与结果查询；业务过程中无需开发者陪同，无需终端、SQL、API 调试工具、手填内部 ID 或手工补状态。

允许必要的人类业务劳动：解释口径、定位来源、核实事实、处理例外、正式决定。禁止把开发者搬运数据、伪造服务回执、填写技术 JSON 当成人在回路。

本轮允许新增和调整完成上述流程必需的客户端、内部工作台、复核与决定界面，不再受“前端只能微调”限制。但不进行与办理无关的全面视觉重做，不建设新三维引擎。

## 部分解耦，不建设通用大平台

建议在现有进程与数据库基础上做模块化改造：

| 边界 | 负责内容 | 禁止混入 |
|---|---|---|
| 通用核心 | 当前身份与资源权限、材料版本与来源、运行记录、任务状态、候选/复核/正式动作、幂等、审计、事务与事件 | 租赁政策阈值、固定四域名称、具体解析 SDK、页面组件 |
| 租赁业务模块 | 客户主档、四域分工、资料口径、红线、方案、客户额度、提额机制、直租/回租要件 | 浏览器状态、供应商 SDK、通用执行器实现细节 |
| 适配与应用层 | 文件/模型/渠道/媒体适配、Edge 投影、客户入口与工作台 | 独立审批权、另一套客户授信数据库、前端自定业务状态机 |

目录名不是目的；优先提取已有代码的真实边界，不全仓搬家，不把所有领域对象降格为任意 JSON，不创造通用工作流 DSL、插件商城、跨行业产品或微服务体系。

只有当前确需替换或隔离的地方才抽接口：材料解析、模型执行、渠道发送、版本化业务政策与证据/任务/决定服务。内核通过受控接口消费业务模块；业务模块可引用通用类型，但不能绕过核心权限和提交校验。业务配置只能表达获得批准的约束，模型文本不能临时改规则或提权。

## 基线和执行纪律

- 本包是新一轮任务要求，不是对当前本地/PR 已通过的认定。各路启动时记录实际本地分支、HEAD、脏文件和相关文件摘要，读取当前 AGENTS.md 与契约。不盲目切到 main、不自动合并 PR、不覆盖其他路已有修改。
- 对此前缺陷先复现：已修保留回归，未修定向处理。不要把“假定前序完成”写成事实；未实现的客户入口、媒体、空间构建单列。
- 每路完成“小范围设计→分批实现→正反例测试→实际链路验证→同条件性能复测→修复再测”。不只交方案或待办。正常范围内连续执行；未授权费用、外发、部署或未定业务规则只阻断相关子项，不猜测批准。
- 不自动 commit/push、切分支、创建 worktree、强杀未知进程或删除未知数据库。提交边界指可审查变更集合，不是 Git 操作授权。一个主 AI 执行上下文；普通测试子进程使用各自登记的资源。
- 不启用真实客户数据、真实渠道或费用，除非已有相应明确授权；不把密钥写入仓库、前端包、日志或报告。真实敏感文件只能进入获准存储和处理范围。
- 先复用性能成果。不以删权限、跳必核项、伪造成功或复用过期结果提速。不追逐没有业务收益的微小延迟差，也不承诺未经测量的倍率。

## 四路唯一修改者

| 路 | 所有权 |
|---|---|
| 01 | Back/A/**、A 迁移与依赖、Back/CONTRACT.md；核心/业务边界和 A 应用接口的集成 writer |
| 02 | Back/B/**、Back/C/**、Back/Connectors/**；各自依赖与默认测试入口 |
| 03 | Front/**、Back/Edge/src/**、Back/Edge/contract/**、Edge 非 e1 测试、Edge 依赖与 package.json |
| 04 | Back/D/**、Back/Edge/test/e1/**、Back/Edge/scripts/**、发布/验收文档和根部交付说明；发布装配 writer |

各路文档位于 docs/product-delivery/goal-01..04/。跨目录需求写各自 INTERFACE_REQUESTS.md，明确接口的生产者、消费者、必需字段、错误语义与截止到哪一阶段需要；由对应 writer 实现。不得把必要接口长期标 OPEN 后自称任务完成。共享新目录必须先明确唯一 writer，不私下争抢。每路自己的 package.json 修自己的测试入口；独立测试由 04 检查覆盖。

## 合流顺序

先由 01/02/03 固定最小实际消费契约，由 04 冻结第一条用户路径与失败判据。随后并行实现，但尽早接通一份原始文件，不等所有模块“全绿”才接线。每阶段进入同一个受控集成版本，由 04 在不再变动的快照上测试。需要调整契约时版本化迁移，生产者和消费者同步；不能用私有 mock 永久代替缺失接口。

独立验收两条线分开：开发者 API/并发测试证明实现；浏览器用户旅程证明产品。不能以前者替代后者。二维完整办理是本轮必须交付，真实媒体和三维未完成则单独保留，不冒充整个最终产品完成。
