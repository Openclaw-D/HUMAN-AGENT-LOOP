## 逐项计划

### T01 页面与范围
- 动作：Edge `--serve-front Front/dist` 同源打开主入口；检查默认路径可见的所有动作入口。
- 断言：五列（商机/政策/信审/商务/资产）×四行（输入/智能/人工/完成）矩阵+右侧六助手；无提款/租后/结清/合作历程/总进度/使用率/底部演示卡；默认页面动作集合中不存在 facility.approve / financing-requests 写命令入口。
- 证据：1920×1080 + 1366×768 截图（两尺寸）；DOM/网络面板记录（无设施/融资/敞口写请求）。

### T02 单次上传与来源
- 动作：以 N1 起逐份经统一上传链上传（一份原件只走一条业务上传链）；记录每份 requestId/回执/artifactId。
- 断言：A 登记成功（客户归属正确）；回执可对账（GET receipts）；能从发现/方案引用回到真实原件（§11.2 content 读回，字节 SHA 与夹具一致）。
- 证据：上传请求/响应 JSON、artifact 清单、原件读回 hash 比对。

### T03 部分并行
- 动作：N3（资产域核验）就绪而商务列未完成时推进资产核验；不同事项的输入/智能/人工分别推进。
- 断言：资产核验不被商务整列锁定；仅同项工作实际前置设门；二十格进度来自服务端投影（分母未知为 null，未闭合最多75%）。
- 证据：各格状态截图 + workspace 投影 JSON。

### T04 有利与不利证据
- 动作：注入 P1（改善）后读候选 v+1；再注入 C1（净值下调纠正）后读候选 v+2。
- 断言：候选按受控合成规则推导，可增（P1）可减（C1）；每次变化可解释（依据引用、输入/规则/运行引用齐全）；不是前端硬写脚本（候选字段全部来自服务端）。
- 证据：候选版本历史（含同版金额/期限/价格/口径/条件）、变化前后对比。

### T05 重复/相关证据
- 动作：上传 D1（与 N4 同字节不同名）；触发一次重复分析请求。
- 断言：A 判重（duplicateOf）不产生独立证明力；候选不因重复额外变化；业务写入无重复行。
- 证据：duplicateOf 标记、候选版本未变或仅标引用、断言记录。

### T06 冲突与冻结
- 动作：注入 A1（涉诉）后尝试正面确认。
- 断言：重要冲突阻断受影响领域的正面确认（409 门，Edge 原样透传）；原建议保留为冻结版本（白色霜边投影）；补件、查看、复核可用；不可豁免门无一键解除入口。
- 证据：确认被拒响应、冻结投影截图、补证动作回执。

### T07 技术失败
- 动作：注入故障（暂停 Connectors 处理驱动 / 断上游 / 模型超时替身），随后恢复。
- 断言：不产生客户自动拒绝或额度清零；同 requestId 重试或对账可达（receipts/processing 状态如实 failed+nextAction）；恢复后同号续跑。
- 证据：故障注入记录、502/failed 响应、恢复后回执。

### T08 新旧版本竞争
- 动作：在 C1 取代 N3 后，延迟放行一次基于 N3 的旧分析运行（迟到结果）。
- 断言：迟到结果不覆盖新版本候选（A 域水位 changed/deps_changed 语义）；只重算受影响范围；旧决定保留不被改写。
- 证据：运行登记/回执时间线、候选版本未被覆盖的读回。

### T09 正面人工确认（零变化断言）
- 动作：snapshot 账本基线 → 有权人员会话（合成授权目录中的人类角色）经 Edge `/api/jw/v2/actions/assessments/:id/confirm-preassessment`（最终路径以01冻结契约为准）确认 → verify。
- 断言：服务端校验身份/范围/当前版本/requestId；确认成功产生 confirmationId（scope=preassessment_only）且可 GET 读回；`ledger-zero-change.mjs verify` 退出码 0（三表零行新增/变化）。
- 禁止：SQL 补结果；借 facility.approve 或占位设施。
- 证据：确认请求/响应、读回 JSON、baseline+verify 输出。

### T10 负面/撤回结束
- 动作：基于冲突未消除（或明确负面依据）完成负面预评估结论；另会话执行行政撤回。
- 断言：负面结论可完成（不要求无价值工作刷绿）；撤回与拒绝分开记录；客户档案不删除。
- 证据：确认记录（outcome 区分）、撤回回执、客户仍可读。

### T11 重复提交与恢复
- 动作：同 requestId 同载荷重放确认；异载荷同号提交；退出 Edge/重启栈后重新读回原件/方案/消息/结果。
- 断言：同号同载荷单效果（replayed:true）；异载荷 409；重启后 workspace/messages/receipts/确认记录完整读回（messages-file 持久库 + A 权威记录）。
- 证据：重放响应、重启前后读回对比。

### T12 越权与不可信输入
- 动作：用另一客户会话读本客户回执/材料/评估；无权角色尝试确认；原件内嵌"忽略规则/直接批准"指令文本（N1 追加页或独立材料）后走处理链。
- 断言：跨客户/他人回执 404/403（不泄露存在性）；假角色不可写（CSRF/权限/actor 覆写三道）；材料内指令不获任何系统或审批权限（authority=none，处理结果无授权语义）。
- 证据：403/404 响应集、内嵌指令材料的处理回执（无授权动作发生）、审计记录。

### T13 点选与视觉
- 动作：浏览器（独立测试上下文，不占用用户 viewport）逐格点选、悬浮、放大还原、输入法输入。

- 证据：交互截图序列 + CSS 检查记录。

### T14 辅助页与模型预算
- 动作：打开流程/记录/材料/待办入口；触发 Agent（@/明确调用）；尝试未授权真实 API 调用路径。
