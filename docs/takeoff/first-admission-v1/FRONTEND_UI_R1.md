## 产品纠偏

- 删掉首页说明墙、进入办理中间页、账号/凭据输入与 Edge 地址框。首屏直接五专业角色，点击调用现有服务端身份交换；不存在的角色禁用，不使用 admin 代替政策等岗位。
- 当前配置开放业务、信审、商务、资产；政策没有对应身份，显示暂未开放。管理、机器服务身份不进入普通角色卡；多个同岗身份须明确选择，不静默取首个。
- 客户目录收敛为搜索、客户列表、新建客户；新建表单默认收起。后台授权目录决定可见范围；旧最近访问缓存不作为越权直达入口。创建使用当前会话租户。
- 顶部客户/建议方案，左五列四行，右六助手保持。黑白灰布局、少量状态色；工程解释移入依据详情，聊天明确为规则简报且未连接模型。
- 黄扇区是已知局部进展，黄角标是待处理；红角标仅明确业务阻断，技术失败用待处理文字区分。绿圆仅真实办结；未知分母不编造百分比。
- 格子显示真实到件数或下一步状态。修复 Edge 未识别 A 原件 material.kind 前缀导致到件为零；解析派生记录、重复件、被取代件不重复计数。未改变业务判断、确认门或数据。
