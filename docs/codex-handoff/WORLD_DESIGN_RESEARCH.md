# 见微世界 · 交互研究与设计候选

2026-09-19：本轮定向阅读任天堂官方开发者访谈与 MDN；不是完整游戏研究，也未开展实机测试。用户已确认方向见 NORTH_STAR.md；以下转译为 Codex 设计建议。

## 来源与转译

1. 任天堂《王国之泪》开发者访谈 Part 5：鼓励玩家按自己预期探索，物体可操作性用一致视觉规则表达，空间声音传递距离。转译：可操作设备/人物/水滴使用统一提示；任务有推荐但可绕行；接近对象才出现上下文动作；远处声音渐弱。不是照搬塞尔达资产或唯一解谜路线。
https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-9-the-legend-of-zelda-tears-of-the-kingdom-part-5/

2. 官方 Part 3：场景之间保持连续体验，背景音乐随情境变化。转译：全国旅行到喀什有镜头/声音过渡，进入工作本保留现场上下文，关闭面板回到原位；音乐避免每次开面板重新播放。
https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-9-the-legend-of-zelda-tears-of-the-kingdom-part-3/

3. MDN Gamepad API：查询连接的设备、轴与按钮，检查 standard 映射，处理连接/断开；浏览器可能等用户按键才暴露设备。转译：开始页提示按 A，统一动作与焦点层；真正验收使用目标 Xbox 手柄与浏览器，不以 API 可用推出所有设备兼容。
https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API/Using_the_Gamepad_API

## 首个可玩切片建议

开始/音量→业务身份进入→日历选喀什项目→全国地图前往→探索现场与见微互动→打开一个资产或材料面板→离开后大水滴留守→自由返回。推荐演示约5分钟，但世界不锁死此路线。

能力先体现角色工具与见微辅助配置；成就候选为首次完成来源核验/完成协作/发现材料缺项，不以审批通过率驱动奖励。具体数值、成长树、多人同步、音乐曲目、CG分镜均未冻结。

## 技术验收建议

输入动作与业务命令分开：移动/视角每帧更新，业务确认仅按下沿触发；返回关闭当前最高层面板；焦点恢复原对象。镜头切换不切身份/位置。键鼠与手柄提示随实际输入切换。未识别映射提供校准提示，不猜测键位。
