# JW 当前北极星：业务二维作业看板

用户最新明确冻结，替代见微世界、3D、地图、游戏化、手柄及复杂决策树前端方案。本轮不回滚代码、不删除旧原型；停止其新增投入。

只做一个横屏平面2D业务作业面板，卡片和少量图标文字，清楚的空间分区、流畅展开与状态反馈；不以表格为主界面，不做立体场景，不另建图形编辑器。

客户需求为起点，覆盖单项目商机→尽调→政策→信审→商务→资产管理与按合同结清。业务为主要使用者，其他岗位通过任务/意见/回执协同；职责与阶段不强制一一串行。缩短办理等待和重复劳动，不提前改写合同期限。收益、客户接受度与资产风险平衡，正式规则与人类权限保持。

喀什合成案例：邦德激光设备采购500万元、申请融资500万元，不等于全额融资已获批准。未确认的利率/租期等不虚构为制度。

复用现有真实客户工作本及Edge/A/Connectors，旧home-overview仅作布局参考，不把旧模拟重新包装成真实业务。现有后台缺失能力须如实列出，不能用disburse/settle直接声称完整租赁起租与结清。
