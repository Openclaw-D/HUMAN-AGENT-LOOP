## 打开方式

双击本目录index.html浏览三套材料。每套包含原始材料阅读册.pdf、经营台账.xlsx、originals逐件原件、supplements补件、customer-profile.json客户资料和material-manifest.json来源索引。

PDF原件与Markdown正文同源；经营台账是CSV的展示汇编；接口CSV是同源字段投影。多种格式不能重复计算为独立证据。customer-profile.json中的grade及DEMO_EXPECTATIONS.md属于案例设计信息，不上传为客户证明。

## 数据口径与真实程度

- 2023、2024、2025完整年度，2026年1-8月；另可筛选最近12个月2025-09至2026-08。不得把八个月当成全年或直接与全年同比。
- 原始台账金额为人民币元；接口财务和设备CSV的_wan字段是万元；requestedAmountMinor是分。
- 净利润、应收、存货、现金、固定资产折旧和权益按月滚动。分红作为筹资活动现金流，未混为经营支出。银行流水与订单、采购有关联编号。
- 模拟简化了科目、税种、纳税时间、人员明细和生产粒度。不是法定全套报表、正式税表、真实征信报告或有效证照。长期应收未计提减值属于明确风险，不能因为报表平衡就认定资产真实。
- 三种优劣是案例设计目标；实际支持程度必须依证据和当前规则产生，不能硬编码200/500/1000万元为结论。

## 尚缺什么

这不是三套真实企业授权原件。真实现场照片/视频、登记检索、征信查询、签署授权、适用资质及业务人员核验均未发生。示意图不替代照片，补件答复不自动解除风险。当前版本是可浏览和复核的模拟材料基础包；不能称真实客户进件或成熟端到端系统。

页面/接口只完成材料对应设计，尚未上传、接线和运行验收，见INTEGRATION.md。业务终点仍为有权人员确认首次回租准入及授信预评估，不包含正式批准、提款或结清。

## Git与版本

本目录为用户指定的Git交付范围；含CSV、Markdown、PDF、XLSX、JSON、SVG及浏览页。原始旧包、依赖、QA临时图片及凭据不纳入。当前未执行git add、commit或push，不包含其他在制修改。Git放行情况和哈希见校验文件。

后续修改保留版本与来源关系，不覆盖旧版证据后宣称原件不变。当前脚本重建会覆盖本v1模拟输出，仅在明确修订该版本时使用；正式使用后应创建新版本目录。
