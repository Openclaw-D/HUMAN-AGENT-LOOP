# QA · 八个尖锐问题与有依据的简答（V0.3-Z3）

2026-09-20｜每问约 20–30 秒短答，证据定位见 CLAIM_MATRIX 编号（CM#x）。原则：先答问题，无证据就保留"待验证"，不现场翻配置/账单/隐私。

## 1. 你们演示里到底哪些是 AI，哪些是规则？会不会把规则包装成 AI？

答：分开的。上传→解析→五域分析→Gate 全部是确定性规则代码（C 管道标记 simulation+deterministic-extractor）；真实模型只有 Edge 单次辅助观察入口，输入是工作台摘要，输出 authority=none、无审批权。历史 13 次真实 GLM 调用是后端执行记录；页面当前仍以规则简报+明确标注的模型观察面板呈现。界面把"客户说的/系统整理的/待人工核实"分列，我们会按实际构建的标签展示，不把规则简报说成模型理解。

证据：CM#3/#4/#11/#18；`material/REPORT.md`、`tec/ARCHITECTURE.md` §4。

## 2. 材料变了，AI 还引用旧结论怎么办？

答：这个风险我们已经用独立反例复现（候选变化后复用旧答、真实 HTTP 路由同样复现、跨租户同 ID 复用他租户回执），公开列为必修缺陷而不是掩盖。当前工作区已按"完整上下文 hash+配置+提示版本绑定回执、重放校验 payload、响应前重算当前性并二次授权"重构，但在独立复验通过之前，我们只说"已定位、修复在制"，不说已修复。验收标准是：输入变则新请求，不变则零出站幂等，撤权先拒。

证据：CM#2/#3；`.local/v03-eval/cache-repro.log`（pass 2/fail 3，2026-09-20T11:30Z）。

## 3. 模型看过原始材料吗？它给的引用能核验吗？

答：没有看过原件。服务端只传投影摘要（客户名、状态、版本、候选、到件数、阻断数），证据原文与事实明细不出域，输入引用固定为空；模型自报的引用目前没有服务端校验。所以只能评价"基于摘要的辅助观察"，不能说它读懂了材料或引用可回溯原文。授权片段输入+引用校验（G01/G03）是已冻结的下一步，验收以离线捕获出站报文逐字段对应原件为准。

证据：CM#3/#4；真实回执 payloadHash 内嵌摘要文本（`existing-model-audit.json`）。

## 4. 提效到底多少？是不是只挑好看的样本？

答：未测，我们不报百分比。45 条同材料同任务三臂记录全部 NOT_MEASURED，真人测量为 0，也没有真实人工基线——没有基线就不算比例，"未测"不写成 0。合成样本只有 3 客户 15 配置，结果只能样本内表述，失败和返工会计入，不会用旧 API 单次耗时（如 15.7 秒冒烟）冒充业务提效。

证据：CM#6；`eval/raw-metrics.csv`（46 行=表头+45 全 NOT_MEASURED）、`material/REPORT.md` 留出纪律。

## 5. 真实模型调用的钱怎么算？超时那几次算不算钱？

答：确定计费部分 2724 入/14883 出 tokens，按旧报告费率估算约 0.44 元；账本按最坏口径预占 4.2+0.35 元。3 次超时请求在提供方侧可能已计费但未取回，费用如实标"未知"，不计零。预占、差额、估算、实账四个口径分开；费率没有重新查价，真实账单以控制台为准。预算是用户授权的 7M tokens 上限（约 196 元封顶），我们不删账本重置额度。

证据：CM#5/#7；`existing-model-audit.json`（rateStatus="Historical report assumption, not reverified current pricing"）。

## 6. 今天演示的是当前系统吗？旧的验收记录还算数吗？

答：诚实说：现场资源还没冻结。成片/PPT 未制作、排练未计时；前端源码在制而 dist 是旧构建；EVAL 的测试与封存是对 11:32 快照做的，此后源码还在改——旧快照通过不证明当前代码通过。所以上台前必须由 CTRL 冻结"构建 hash+主客户+材料版本+身份权限"，并按真实运行/历史回放/目标说明三种模式明确标注；没有冻结就使用台本里的保守分支讲词。

证据：CM#2/#16/#17；`show/05_FALLBACK_REHEARSAL.md`、`front/DELIVERY.md`。

## 7. 数据隔离和权限怎么保证？跨租户会泄露吗？

答：隔离是应用级的：A 内核逐请求凭据裁决、Edge 逐资源授权、模型等待结束后二次授权（缓存命中也不放行）。数据库层未见 RLS，我们不宣称库级强隔离。EVAL 的跨租户反例暴露的是回执复用层缺陷，不证明真实路由权限被突破（customer 全局唯一、路由先查权限）；该缺陷修复待独立复验。"三表零变化"是生产者自报计数，我们把它当佐证而不是独立数据库验收。

证据：CM#2/#11/#12；`tec/ARCHITECTURE.md` §6（RLS/锁/事务边界）。

## 8. 你说全周期，现在真能结清、返单吗？明天怎么落地？

答：全周期是目标，不是现状。当前可核查证据集中在首次准入预评估子流程：确认记录 scope=preassessment_only，不产生正式授信；没有独立轮次/合同/还款计划表，settle 是一次全额本金结算，不能冒充分期履约或合同结清。落地路径是先在获授权业务范围内按质量、效率、权限、故障恢复验收，再扩展；人力、硬件、单位成本尚无测算依据，我们不承诺"几人几天上线"。

证据：CM#13/#20；`tec/GAPS_AND_ORDER.md` §3（TEC-LIFE-1 候选）、`material/REPORT.md` 生命周期缺口表。
