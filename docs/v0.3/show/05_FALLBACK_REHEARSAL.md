# 运行、回放、模拟与排练

SHOW-R1｜以下是演示操作约定，不授权SHOW更改服务、写库、调用付费模型或重置业务记录。

## 三种模式明确分开

| 模式 | 进入条件 | 对评委的说明 | 可用范围 |
|---|---|---|---|
| A 真实运行 | 当前构建、同客户、授权身份与材料、必要缺陷复验通过；现场环境预演成功 | “这是当前系统运行，使用合成材料。” | 只展示确实已接通且获授权动作 |
| B 历史回放 | 脱敏录屏/截图已核对客户、构建、版本和实际结果；文件存在且离线可播放 | “这里切换到已核对的历史运行回放，运行时间与版本已标注。” | 证明记录时的能力，不证明现场实时或当前版本仍通过 |
| C 目标/模拟说明 | A/B不可用，或该功能尚未实现 | “这一段是目标示意／模拟操作，尚不代表真实业务完成。” | 解释目标、材料和边界，不计作运行、性能或效果证据 |

预置数据不是第四种真实性：若从预先准备的待确认状态开始，在A/B上另标“预置至待确认”；不能说台上刚完成了全部上传核验。模拟签署、模拟收款和时间跳转必须在事件旁明示。真实业务绿灯只来自实际办结，目标图使用灰色文字。

当前包只具备文字排练条件：没有本任务交付的mp4/PPTX，也没有已冻结的当前运行截图。B模式必须等可用文件交付；不能在不存在回放时口头宣称已切换回放。

## 故障时直接照读

| 触发 | 操作 | 讲词 | 继续位置 |
|---|---|---|---|
| 视频无声 | 继续画面，讲者按旁白读；若无法播放，显示静态标题 | “我用一分钟直接说明场景。” | 01:00系统 |
| 系统首次打开10秒仍失败 | 不台上重启，不排查端口；打开已核对回放，若无则目标说明 | “现场连接暂时未完成，下面使用历史回放／设计说明，状态会明确标注。”（二选一念） | 原定当前段，不重置计时 |
| 原件格式不支持 | 保留失败/待人工状态，打开授权原文件说明 | “这份材料目前未完成自动解析，需要人工核对；文件已收到不等于内容已识别。” | 02:25助手段 |
| 模型等待超过10秒 | 停止等待画面；不重复提交、不修改问题绕缓存 | “这次请求还没有明确结果，我先展示已核对记录；未知结果不当作失败后自动重发。” | 继续当前讲词 |
| 发现旧答复或引用不属于输入 | 停止把该输出用于结论；显示已知缺陷说明 | “这里的回答当前性未通过核对，本次不作为业务依据。” | 规则/人工流程或目标说明 |
| 确认按钮禁用/无权/依据过期 | 保留拒绝，不换admin、不伪造核验 | “当前条件不满足确认要求，系统停在这里；后续不能视为已完成。” | 07:10历史段 |
| 确认提交后未知 | 查已有回执/只读刷新；若无终局，不再提交 | “提交结果待核对，不能仅凭等待结束当作成功。” | PPT；后续由归属任务核对 |
| 旧截图客户/版本不一致 | 不作为连续案例使用 | “该图只作另一份历史记录参考，不属于刚才这次办理。” | 最好省略该图 |
| 计时超前或落后 | 超前停顿给看证据；落后按台本压缩 | 不解释技术细节填时间 | 08:00切PPT，15:00硬停 |

10秒是台上等待预算，不是系统超时设置或实际速度承诺。此处不要求修改任何生产/本地服务timeout。

## 排练步骤

1. **文字通读**：现在即可按01和02朗读，缺证据段用默认保守版。记录口述实际时长，不称系统运行排练。
2. **带操作计时**：冻结资源齐备后，从播放到收束连续走一次；记录01:00、03:25、06:00、08:00、12:00的实际时点。每次实写动作只在归属明确的合成演示资源中进行，不为第二遍清库或回退审计。
3. **降级演练**：切换已有本地文件/静态稿验证转场，不人为停共享服务、断用户网络或伪造错误。重播视频不是重复模型请求。
4. **现场可读性**：从实际领导席/侧席看，一次只核对标题、状态文字、一个原件字段和确认边界。看不清先放大焦点或删字；不因画面宽就恢复信息墙。保持用户开发窗口布局。
5. **证据封包**：最终成片、PPT、回放与冻结单一致；复制到获准本地播放位置并离线打开。录屏剪辑若省略等待/人工步骤，明显注明，不用剪辑时长当系统性能。

建议演示前60分钟完成内容冻结，前30分钟做带操作计时，前10分钟只核对播放与入口。这是准备安排建议，未创建定时任务，也不是系统正在后台执行。
