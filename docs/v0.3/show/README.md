## 直接使用

1. 打开 [12 分钟台本](01_RUNBOOK_12MIN.md)，讲者读“讲词”，操作者读“操作”。括号内提示不念。
2. [六页 PPT 内容](02_PPT_CONTENT.md)在系统演示后使用，合计 4 分钟；[60 秒短片](03_VIDEO_60S.md)放在最前面。
3. 上台前按 [降级与排练](05_FALLBACK_REHEARSAL.md)选定运行方式；[证据缺口](06_EVIDENCE_GAPS.md)仍未补齐的主张使用台本中的保守讲词。
4. 另备 [评分映射与十问十答](04_SCORE_AND_QA.md)。问答 5 分钟单列，不挤占 15 分钟展示上限。

## 现场视觉约定

照片 4、5 显示亮环境、较大横屏、侧向观看。先前 3–5 米只是目测范围，缺乏标尺与相机参数，不作设备尺寸或字体计算依据；照片不能确认屏幕分辨率、实际投屏比例或音响效果。

- 黑白灰为主；红只表示阻断，黄表示局部进展或关注并配文字，绿只表示真实办结。
- 首屏只放项目名、一句说明和“合成案例”；不复刻会场蓝色海报，不加入彩色装饰或彩色 logo。
- 每屏一个讲解焦点；总览展示结构，原件、风险提示、确认回执逐一放大。关键结论不依赖小字页脚。
- PPT 建议 16:9 工作稿，现场确认信号比例；标题 40–48 pt，正文 28–32 pt，证据标签 22–24 pt。它们是试投起点，不是已验收尺寸。内容挤不下先删字。
- 保留用户现有浏览器 viewport、缩放和预览标签。现场使用单独演示窗口，调节前确认该窗口归属；不改用户开发预览。
