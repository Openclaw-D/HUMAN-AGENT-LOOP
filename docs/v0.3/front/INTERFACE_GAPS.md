2026-09-20，提交 CTRL 裁决；本路不修改后端。

| 接口/能力 | 核对事实与影响 | 当前前端处理 / 请求 |
|---|---|---|
| assistant/observe 上下文绑定 | 原契约 contextVersion 来自 admission.inputVersion，需求/候选变化不一定推进该水位；无完整摘要 hash，不能证明历史回执对应当前摘要 | 本地完整相关快照锚点变化即隐藏旧输出；replayed 回执暂不展示为当前观察。请与 TEC 冻结 contextHash/tenant/profile 绑定及服务端提交前/完成时版本检查后再适配 |
| 模型原件与事实明细 | 当前上下文为客户/状态/候选/计数摘要，evidenceRefs=[] | 明示“基于工作台摘要；未读取原材料”，不生成引用链接。将来原件输入需要明确解析、事实与版本契约 |

| 全生命周期 | 当前此页面接口只处理首次准入/预评估，未验证正式授信、签约、履约、异常、结清、多轮返单闭环 | 保持总体目标，缺口交 CTRL/TEC 冻结真实业务接口；不得把预评估确认改名为正式批准或把本地状态冒充履约/结清 |
