## 用户只需理解四件事
1. **放入材料**：选择客户后上传，保留原件；系统识别、归类、提取。不要求用户理解通道、工件、规则包或运行编号。
2. **查看分析**：业务、政策、信审、商务、资产分别显示看过哪些材料、判断、依据、缺项。模块分析必须实际产生，不预置好中差结论。
3. **作出选择**：提供有依据的建议选项；需要补充时直接定位对应材料或问题。选择反馈与正式审批分开。
4. **确认本次办理**：有权人员查看本次结果并确认；不足时明确告诉用户缺什么。不得在后台替人做正式决定。

主屏保留当前主要动作；专业模块按需展开。用户最新状态表达覆盖早期颜色决定：浅银铜色实体锁表示未开始/条件未齐，油蓝扳手表示实际处理中，亮绿对勾表示真实完成，红叉仅表示明确失败；缺失不显示红叉。客户名、材料名、动作名直接使用业务用语，内部技术标识仅用于后台引用。
