## 实现

- 回执版本 2：稳定 SHA-256 覆盖租户、客户、评估身份/修订、完整服务端上下文、助手、问题、实际提示词及提示词版本、非敏感模型配置。排除密钥及投影 scope.asOf；业务生效时间仍是依据。模型路径、非敏感查询参数、模型、输出上限等纳入配置身份。
- 命中后比较完整 identity 和回执顶层身份、载荷；不再仅凭 inputVersion。旧成功回执保留历史，可在显式分析时建立新身份；旧 unknown/intent 或坏记录失败关闭。
- 同进程同持久目录合并在途请求；跨进程 wx 原子占用，新鲜读取终局。意图和终局分文件留存；崩溃残留占用不按超时回收，不盲重发。损坏文件、身份不匹配或存储失败返回 unknown。
- Edge 在任何回执读取前鉴权，等待模型后重新验证会话、权限和工作台；变化或无法读回时 current=false，不向页面返回旧观察，原回执与用量保留。撤权返回拒绝。
- 响应追加 receiptVersion/contextHash/configHash/current。前端要求 v2 完整标记且 current=true，并读回工作台比较本地上下文；合法缓存可展示，旧接口保守隐藏。取消未经服务端核验的本地直接复用。
- 没有新增业务写入/审批权限，没有调用付费模型，没有修改共享运行配置或重启现有服务。
