## 客户工作本（内部身份）——客户为唯一工作上下文

- **顶栏**：客户名+ID、连接相位徽标（实时/重连/连接中/未连接）、客户状态、身份+角色（只读）、返回目录、退出。
- **主体区（页签）**：
  1. **材料·原件**：材料清单（种类/事实键/核验等级/现行与取代链/主体期间/对象锚定/登记时间）；事实冲突显式列出（不 last-write-wins）；上传表单（种类/事实键/主体/期间/真实文件 ≤512KB）+ 二次确认；预览显式"待上游 IR-03-3"。
  2. **核验**：findings 队列（未决/已处理）+ 有理由关闭（理由必填+引用现行证据）；新登记质量差异（严重度）；检查会话核验项（人工核实按钮，名册角色服务端裁决）；对象锚定清单（二维保真，三维/视频显式未接入）。
  3. **问题·补证**：会话卡（runStatus/closureStatus/开放问题/在途外发）+ 开始会话/暂停自动提问/恢复/人工接管；服务端 next-actions 展示；本会话提问（受众=对客户/内部 × 目标角色 × requiresHuman）；回答按钮仅角色匹配时出现（服务端仍强制）。
  4. **方案·决定**：decision-status 权威投影（就绪状态/依据包/Gate/候选≠批准≠可用三行/阻断动作）；评估列表（authority=none 明示、金额未知标未知）+ 创建评估（credit）；正式动作（提案/批准/激活/暂停；用信申请/预占/承诺/出账）全部**二次确认对话框（动作+对象+金额+幂等编号）**；在途申请列表（标注非权威清单 IR-03-4）。
  5. **结果**：报告三视图生成/清单/Markdown+JSON 导出（主体绑定前提显式提示）；requestId 回执对账；最近事件（正式历史只追加）。
  6. **受限邀请**：创建（角色×白名单×有效期×备注）→ code 明文仅一次弹窗；清单（状态/到期）+ 撤销（即刻生效）。
- **右栏**：待办（服务端 openItems 口径）、四域矩阵（复用 DomainGrid；绿=该域冻结结论当前、灰=未开始，均非"通过"）、额度与决策要点（复用 edge-logic 投影）、非权威清单提示条。
- **底部沟通（常驻）**：对客户/内部显式分列双栏；受众切换按钮；服务端回执状态（发送中/已送达（服务端回执）/失败：码）；明示"页面内消息办理，不显示已送达企业微信"。
- **页脚**：演示租户、Edge buildId、受限能力标注（预览待上游/邀请待上游→已接线/视频三维未接入）。

## 客户门户（客户联系人身份，自动分流）

- 顶栏"客户联系人视图（仅获准披露内容）"；我的材料（白名单投影：kind/时间/stage/失败原因/下一动作）；提交材料（种类须在邀请授权白名单内，服务端强制）；与办理方沟通（对客户受众）。
- 撤权/过期 → 401/403 终态：清会话回登录页 + 明确文案；全程不显示内部评估/额度/报告。

## 错误与状态语义（全局）

- 错误码→业务语言映射（wb-logic.errorText）：POLICY_PENDING/GATE_BLOCKED/STALE_BASIS/REVIEW_REQUIRED/BASIS_PACKAGE_REQUIRED/VERSION_CONFLICT/UPSTREAM_UNKNOWN/FILE_*/INVITATION_* 等；未知码保守回显。
- 颜色：绿=指定事项完成（≠授信通过）；蓝=进行中；黄=待复核；红=禁止/失败；灰=未知/未开始——全部带文字。
- 幂等：所有写动作带稳定 requestId；重复点击被服务端幂等表吸收；502 结果未知 → 显示"对账中/请勿重复提交"，结果面板可按 requestId 对账。
- 会话：30 分钟 TTL（Edge 内存）；auth 帧/401/403 = 终态要求重认证，不自动复活；切换客户走代际守卫（迟到响应不串入新客户）。

## 续轮新增（2026-09-19，goal-03d）

- **材料·原件**：+「处理通道」卡（ChannelCard）——通道邀请（code 仅一次）/接受绑定/上传进通道（≤512KB）/分段进度表（排队·处理中·已完成·对账中·重复跳过）/任务回执（阶段留痕 + A 侧留痕 aOps：材料/运行/Gate 回执引用）/原件预览（Connectors 签名 URL）/暂停调度；A 工件行 +「处理状态」（G3 回执 current/history）。
- **核验**：+ 通道人工路线——人工录入（多行 `factKey,value[,unit]`+定位+理由=转录）、事实更正（修订链）；获准复核在问题页。
- **问题·补证**：+ 通道补证问题列表（prepared_questions：待处理(suggested/open)/已回答/已复核）+ 行内回答与获准复核（verified 唯一来源）；检查会话动作 +「结束会话（收口）」（ready_for_assessment/pending_evidence 如实呈现）。
- **方案·决定**：+ 依据包冻结表单（Gate 回执引用自动同步自通道回执、四域依赖声明、豁免引用、收口引用自动带会话）；+ 依据包详情（四域意见/当前性/缺口，只读透传）；+ 域意见登记（域目录角色限定、引用真实 runId、authority=none 恒定）；+ 信审候选表单（倾向/支撑金额可空=未知/理由）与提交复核；提案强制绑定依据包。
- **受限邀请**：+ admin「撤权客户身份」（IR-03-7 页面化，级联停用 cit_*）。
- **错误语义**：+ TOKEN_INVALID/TOKEN_EXPIRED/INVITATION_ALREADY_USED/INVALID_STATE/NOT_READY/ANALYSIS_RUN_NOT_COMPLETED/ARTIFACT_SUPERSEDED 等业务语言映射。
