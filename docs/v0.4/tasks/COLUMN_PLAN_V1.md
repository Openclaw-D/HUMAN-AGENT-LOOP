# V0.4 左右跨页联动：单一分阶段计划

状态：用户要求先规划，暂停旧零散实施。此计划统一取代旧左右交互契约中互相矛盾的实现指导。当前只冻结规则与实施顺序，不声明运行时已切换Plan mode、不授权立即整包实现。

## 一、用户可见规则
新开一次三例合成演练：初始五专业列均显示锁，保留平台/材料/决策/流程四个独立页面。不能为得到全锁而清空或覆盖已有业务历史；已运行流程刷新恢复原进度，重新演练另有新processId。
右箭头是“推进下一专业列”，不是切页面、不是只选中下一列。一次触发本列完整处理，真实结果回来后本列四格全部绿勾；等待时明确正在处理。不得一按就用前端计数把未执行结果画绿。后列依赖已满足的材料/分析格同步更新为相应真实状态：未满足仍锁、已完成绿、实际执行中显示处理中，不能五列互不影响。
以示意状态L=锁、G=完成表达好例主路径：初始 LLLLL → 第一次 GLLLL → 第二次 GGLLL → 第三次 GGGLL → 第四次 GGGGL → 第五次 GGGGG → 全屏大钻石。这个示意只表示每列是否全绿；后列内部材料/分析格可提前变化，不等于整列提前完成。
中例：业务→政策→信审补证暂停→补证后信审完成→商务→资产，约六次主要推进，最后钻石。差例：业务→政策→信审明确否决点→大红叉，后列停止并有原因，保留记录归档，不假绿、不继续成功路径。
左箭头只“回看上一列结果”，不能撤销或重跑业务；明确当前查看列与已完成进度分开。回看后右键对已有结果只前进查看，不重复执行；越过已完成边界才提出下一列推进。页面路由/滚动/画布位置始终不动。
三个客户是受控合成演练的预期路径，必须用符合条件的材料/规则与真实动作支撑；不覆盖真实结论或审批，不将模型候选当正式批准。正式人类确认仍在本列清楚呈现，不能隐藏绕过。缺失接口或未具备执行权限必须在计划阶段指出，不等到前端把按钮禁掉才告知。

## 二、一个服务端状态、四种视图
唯一状态至少含customer/processId、当前查看列（UI）、服务端完成边界/每格状态、运行轮次、待处理/补证/拒绝、材料版本、候选与人工选择、最终结果及事件版本。前端不得维护四份各自推进的业务状态。
平台显示本列/后列进度；材料对应该列实际收到/引用的版本；决策对应依据/候选/实际选择（黑灰反色加粗，其余白灰）；流程对应同一轮事件/身份/时间。四页同一确认版本相符，换页/刷新后可恢复，不混用新旧结果。

## 三、实施与验收顺序
阶段1：主协调核对当前实际接口、状态来源和三例材料，收敛一张状态转移表、最小API清单及文件ownership。明确哪些现成、哪些缺失；不再只往旧契约叠加概念。产出可执行的第一列闭环任务。
阶段2：仅好客户第一列纵向闭环。先实现后端一列请求→真实执行→持久结果/后列依赖更新，再接右键和四页。同一次点击：业务列真实全绿、后列材料/分析随依赖变化、四页版本一致、页面不动。重复点击/未知/刷新不重复执行。通过这一步后才进入下一阶段，不能先画五次全绿动画。
阶段3：复用已验收机制跑完好客户五列，全部完成后钻石；左回看及右复用结果验证，不复写业务。随后增加中例补证一轮及差例信审否决/归档，四页逐轮对照。
阶段4：串行前后联调与用户视觉验收，再执行已准备的隔离长测。长测不能替代前三阶段功能接通；不以截图或模块测试替代真实点击闭环。

## 当前执行边界
Front/Back收到暂停零散实施通知；主协调下一次明确下发阶段1/2后再执行，不自动整包续跑。保留其他任务已有改动，禁止跨对话控制或反馈、subagent/worktree/未授权发布/共享服务重启。当前任务未修改产品代码或用户浏览器。

## 用户最新操作要求与阶段1接续授权
用户明确要求直接落地：不新增图标或额外操作，不让用户操心执行/刷新机制。右箭头每次执行一个专业整列，本列结果、相关流程图、历史服务端时间戳自动更新，再次点击继续下一列。不得只切显示列或新增图标冒充执行。材料/决策仍与本列真实结果同步，保持页面位置。
本次指令解除上文“等待下发”的阶段1暂停，仅启动第一列前后端真实闭环；后续列复用按计划逐步验证。不再继续仅写规划。前端自动处理请求、等待、重读及错误反馈；处理中避免重复提交，用户无需额外刷新按钮。失败/未知等保护属于实现职责，不增加用户操作负担，也不能隐去实际失败或伪造成功。
Back按ARROWS_REAL_WIRING既定ownership完成第一列真实HTTP动作与持久结果/事件/服务端时间；Front按其ownership将现有右箭头接上，自动更新列、材料、决策/流程和历史。不得由前端点击计数直接写绿勾或客户端时间戳。当前专业可在既有文字中标示，不另加新图标。
第一列验收为实际点击一次、后端有对应命令与回执、本列完整结果、流程及历史自动更新且同版本，重复点击不重复执行。页面不滚动/平移。Back未提供可运行接口前Front不能称功能完成；只在各自任务报告实际结果与具体缺口，不跨任务消息/控制。保护其他在制writer与用户运行环境，依既定资源边界实施。
