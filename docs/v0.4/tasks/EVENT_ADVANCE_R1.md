## 业务语义
五专业为业务、政策、信审、商务、资产；四行/四步是通常展示与办理节奏，不是强制五专业串行或一按全绿。各专业按依赖异步运行：某处材料完成可使其他相关专业进入处理中/待重评；只更新受影响环节，不抹掉历史。信审拒绝可以提前结束且阻止不允许的下游；需要补证时新增补证/重评轮次，可能五轮或更多，不预设最终结果。
按钮需说明本轮将执行什么；仅调用当前身份可执行的已有业务命令。正式审批仍保留有权人明确确认，不能一键越过权限。请求被接受≠完成；running期间禁止重复触发；未知恢复回执而非改ID重发；按钮刷新/客户切换/进程重启不能解除未知围栏。不因用户要求“完成一轮”伪造成功、材料或置信度。
所有页面用同一客户持久事件及服务端版本反映进度；每步可查谁、时间、动作、材料依据、候选与置信度、判断摘要和结果。confidence未校准标明，缺值不造百分比；不生成隐藏思维链。四次每客户/十二次五分钟降为常见展示目标，不覆盖真实拒绝或补证分支。
