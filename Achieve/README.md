# Achieve · 按需查询的历史与证据

用户指定目录名Achieve，用作归档。Anthropic/保留旧目录相对路径和历史文档/源码原文；Migration/为此次分析、清单与验证。这里不是当前开发入口，旧AGENTS/DECISIONS/派工授权不自动生效。

媒体、大文件、数据库和运行缓存等未迁入内容仍在原Anthropic，查Migration/excluded.json。这里不是全量旧系统备份，不代表每个历史版本都已完成独立运行验证。
