## 已被替代的旧当前口径

- V4/V5作为当前执行阶段 → V6-CTRL。
- A2A协议优先、彩色拼图或旧专业壳牵引本轮开发 → 现有业务横条稳定性与手机体验优先。
- 用户交流和产品界面均尽量全中文 → 对话中英各半，产品中文。
- 旧任务准备归档 → 已归档。
- 按一周日期表推进 → 暂不按天排；先确定当前主次与依赖。
- 历史无限续跑/自动补位 → 仅当前获授权有界任务。
- 真实模型不在当前工程、先反复稳定预设看板 → Dify优先真实协作闭环；稳定性作为复用和回归要求，不再独占主线。
- 自有后端另建Agent编排、以后再接Dify的草案 → 直接以Dify承担编排，自有后端保留业务事实和接口适配。
