# 见微 Roadmap

状态：`GATE-BASED / FINANCING LEASING ONLY`

本路线图描述同一内核的成熟过程，不代表三个独立产品。任何阶段都必须保持：模型无业务权威、具名 Human Gate、追加式 Evidence/Event、受控 Context Packet、外部动作真实 Receipt、失败关闭和低侵入 Adapter。

## R0｜2026 黑马决赛外网演示

目标：用一个合成融资租赁事项证明业务、政策、信审、商务、资产之间的连续协同。

范围：

- 1920×1080 黑白灰工作台；
- 四板块、二十个差异化工作页；
- 全域图谱与当前流程业务矩阵；
- 单次 Evidence 接入、共享 Context Version、四路候选准备；
- 进程期 append-only Authority Event、四路 Stage Run 历史和只读分页查询；
- 候选 Chat、具名 Human Gate、Decision/Fact Receipt；
- 幂等、冲突、错误、超时、并发和失败关闭；
- Unity 只作决赛开场叙事，不拥有业务状态。

Gate：

- 20/20 页面内容、图谱、矩阵和接续语义不重复；
- 单一黄金事项可以从材料接入讲到资产回流；
- tests、lint、build、HTTP quality/soak 和 1920×1080 浏览器 Gate 通过；
- Event sequence 有序、重放不重复，Projection 审计计数与事件/Stage Run 账本一致；
- 所有材料标注合成/脱敏；
- 页面明确区分本地候选推理、live model、候选状态与正式决定；
- 答辩不声称已接集团系统或达到生产级。

停止条件：若为赶进度而引入真实敏感数据、模型自动审批、假 Receipt 或第二套业务状态，停止并回到契约评审。

## R1｜受控试点内核

目标：从“重启即清空的演示”升级为可恢复、可审计、可授权的受控试点。

候选工作：

- 持久化 Event/Evidence/Fact/HumanGate/Action/Receipt 账本；
- 事务级幂等、唯一约束、并发写入和事件重放；
- 用户、组织、角色、事项成员关系与 RBAC；
- 审计日志、递归脱敏、备份/恢复、迁移账本；
- read-only / shadow Adapter，先读后写；
- 规则版本和 Agent 能力注册；
- 最小评估集：正确路由、证据完整、越权拦截、失败关闭、恢复一致性。

Gate：

- 服务重启和恢复后权威状态一致；
- 越权、重放、伪造 Receipt、跨事项数据泄漏测试通过；
- 至少一位业务、一位大风控成员完成真实但脱敏的具名接力；
- Adapter 可禁用、可回退，不要求替换现有系统；
- Time-to-First-Value 有可测基线。

## R2｜集成试点与移动尽调

目标：把少量真实系统和自研 Agent 接入同一连续事项，并让现场信息一次采集、全程复用。

候选工作：

- 移动端拍摄、OCR、材料分类、问题生成和离线/弱网队列；
- 政策规则/模型、合同、物流、资金、资产监测的受控 Adapter；
- Adapter shadow → read-only → 有 Gate 的 write 三阶段；
- 外部动作 correlation id、超时、查询补偿、unknown Receipt 和人工恢复；
- 局部回流任务、ImpactSet 与多版本对照；
- 业务价值指标：重复上传次数、补证往返、人工等待、定位时长、回执完整率。

Gate：

- 数据授权、字段最小化和保留策略获得正式确认；
- 每个写 Adapter 都有具名 Gate、真实 Receipt 和回退方案；
- 现场一次输入确实减少后续重复工作，而不是只增加一个入口；
- 关键结果能回链到原始证据和人工决定。

## R3｜规模化与运营治理

目标：只有在真实试点证明价值后，才扩展为可运营的多事项协同能力。

候选工作：

- 多事项/多组织隔离、容量规划与限流；
- 事件保留、归档、法律留存和可证明删除；
- 可观测性、SLO、告警、灾备演练和故障手册；
- Agent/模型评估、漂移监控、成本与延迟预算；
- 能力注册、版本治理、灰度发布和回滚；
- 责任接续质量、人工覆盖率、误路由率、证据缺口和业务结果的持续评估。

Gate：

- 真实用户和流程数据证明持续价值；
- 安全、合规、性能、恢复和治理 Gate 通过；
- 扩展范围不会把见微变成替换全部系统的重平台；
- 每个新增板块或行业都先证明对象、角色、权威和 Receipt 契约可以复用。

## V1 / V2 / V3 对领导的成熟度表达

| 成熟度 | 含义 | 不等于 |
| --- | --- | --- |
| V1 | 轻量接入、文本入口、受控上下文、基本 Gate | 另建一套系统 |
| V2 | 关键可视化、连续投影、Evidence/Receipt、少量 Adapter | 全自动审批 |
| V3 | 主动感知、移动现场、完整图谱、跨阶段智能协同 | 已在内网生产落地 |

外网演示可以展示 V3 的目标体验；真实内网落地仍必须从受控、低侵入、可回退的 V1/R1 Gate 开始。
