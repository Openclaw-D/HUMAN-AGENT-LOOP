## 2. 三大阶段

前端最上方固定三栏，既表示模块归属，也表示业务宏观阶段：

1. `I 输入`：上传图标；核心节点为商机。
2. `II 处理`：扳手图标；包含协同、见微（智能）以及业务作战兵团。
3. `III 输出`：下载图标；核心节点为价值。

## 3. 模块层级与图标

- `商机`：钥匙；客户与供应商前端信息从这里导入。
- `协同`：握手；领导层独占的最高统筹层，视觉上必须独一档。
- `见微（智能）`：眼睛；连接中枢，包含 AI、IT 与开发能力。
- `业务`：皇冠；项目的 Case Owner 与作战指挥中心。
- `政策`：拒绝 / X；表达准入与禁止边界。
- `信审`：盾牌；表达信用风险保护。
- `商务`：纸质合同；表达合同、报价与交易条件。
- `资产`：钻石；表达设备、资产与价值载体。
- `价值`：奖杯；主表达“本期 / 本年可验证净收入与单位资产产出效率”，辅助表达全周期利润预测与长期影响；短期为主、长期为辅，二者兼顾。

必须使用同一套简洁 line icon，不混用 Emoji、卡通或不同视觉家族。

## 4. 关系与 Authority 边界

- `商机 ↔ 见微（智能）`
- `协同 → 见微（智能）`
- `见微（智能） ↔ 业务`
- `业务 ↔ 政策 / 信审 / 商务 / 资产`
- `见微（智能） ↔ 价值`

`业务 + 政策 + 信审 + 商务 + 资产` 必须被一个可见但克制的虚拟圆包围，表达同一个作战兵团；业务居中并领导流程。

业务可以主导、发起、终止流程，可以 `@`、邀请和组织任何相关人员处理问题；但业务无权强迫任何人作出决定，也不能替政策、信审、商务或资产完成专业判断与 Gate。

协同可以统筹目标、统筹全局和派发任务；不能借统筹权替代专业判断。
