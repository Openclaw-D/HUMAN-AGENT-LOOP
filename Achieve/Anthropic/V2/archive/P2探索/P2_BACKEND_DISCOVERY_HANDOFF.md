## 2. 当前冻结

- 产品：见微-人机协同平台。
- 决赛：2026-09-21，融资租赁单一业务范围。
- 后端唯一一级业务事项：融资租赁事项。
- 组织主线：业务对大风控。
- 业务：触达供应商、获取和推进商机、联系和服务客户的销售及业务人员群体。
- 大风控：政策、信审、商务、资产；重点是信审，且信审与政策高度关联。
- 每个事项只有一条总生命周期；从商机和尽调进入政策、信审、商务与资产存续，起租不是终点。
- 风控是显性优势，但见微不是单一风控 Agent。

## 3. 最新冻结：政策产品地位

- 政策产物是每个事项必经的控制输入，政策人员不是逐项目审批人。
- 政策板块建设和维护模型评分、策略、反欺诈、规则、引擎能力和必要数据基础。
- 每个事项应用对应版本并保留结果；新问题、冲突、解释不清、重大变化或例外时，政策人员才进入具体事项。
- 信审消费政策产物并承担项目风险判断责任。

该政策语义已关闭，不再作为待确认问题。

## 4. 最新冻结：业务流图与挂载结构

- 后端是一条围绕同一融资租赁事项运行的业务流图：商机获取 → 尽调 → 政策能力应用 → 信审/风控判断 → 商务执行与起租 → 资产存续。
- 该图允许补证、重评、例外、回退和下游结果反馈，不是不可回退的单向流水线。
- 产品结构为“大业务流 + 小协同内核 + 少数可插拔能力接口”；各专业库和 Agent 完成具体工作，见微维持调用、上下文、人工权威、事件、证据与回执。
- V2Z 只在独立目录实现短周期候选接口，不能写入主方向目录或反向冻结产品。

## 5. 最新冻结：异常驱动自动化

- 业务找到客户并确认设备融资需求后，系统应尽可能在正常路径自动采集、校验、调用能力、定位问题、路由上下文和推进事项；异常、高风险或权威决定才找人。
- 该自动化覆盖商机、尽调、政策、信审、商务、起租和资产存续。
- 移动端是业务尽调高频入口；设备照片和现场文字只是带来源的候选证据，不自动成为权威事实。
- 三至五分钟是现场问题定位与补充提示目标，不是完整授信或全流程完成承诺。
- 路线先后端内核，再少量关键可视化，最后完整可视化与主动感知；正式 P 编号未冻结。

当前唯一待确认问题改为：默认自动推进中哪些动作必须保留具名 Human Gate。

## 6. 后续收敛顺序

依次讨论：精确生命周期 → 主体与权限 → Context Packet → AI 推荐与人工选择 → AgentRun/HumanGate/Action/Receipt → Event/Projection/持久化 → Adapter → 模型证据与最小验收闭环。

## 7. 最高产品 Gate

必须回答如何与现有规则、系统、人员、身份、内网环境和自研 Agent 最小化融入：低侵入、复用、可回退、失败关闭、短 Time-to-First-Value，不建设重平台。

## 8. 外网与实现边界

- 当前只在外网使用合成、去标识和公开材料。
- 不索取、复制或推断未授权内网代码、客户数据、制度全文、凭据或商业秘密。
- 原系统保有其业务事实权威；模拟 Adapter 不得写成已接集团系统。
- 模型无业务权威；AI 推荐，人最终选择；高风险动作显式人工 Gate；外部动作必须有回执。
- 后端产品契约完整冻结前，不编码、不调用 GLM、不重做 UI、不启动前端、后端或连调任务。
