# BRANCHES｜三类人工处理路径（确认/纠正/退回）

所有路径都是**有限路径**：边界编码在 `demo-story.json` 的图结构内，由 `candidate/demo-state.mjs` 执行并由 `test/state-machine.test.mjs` 断言（29/29 通过）。人工决定节点：`DD-07`（尽调疑点）、`DD-07B`（补充后重判）、`SG-02`（签约前复核）、`SG-02B`（签约补充后复核）。模型意见不能替代这些节点（节点文案与测试均断言 advance 在此暂停且报 `MUST_DECIDE`）。

## 前置状态（三路径同一起点）

`DD-02` 系统标记疑点 **DD-DOUBT-1（产能口径矛盾，合成）**：首次沟通纪要"基本满负荷运转，订单排到三个月之后"（M1-DOC-01 v1）vs 现场问答"约一半产能在跑"（M1-DOC-08 v1），并与电费记录（月均约4.1万kWh，M1-DOC-05 v1）存在张力。两处陈述双侧绑定来源，不判定真伪。随后并行组 `DD-03`（财务/生产现场补充+客户时点说明）、`DD-04`（资产复检建议）、`DD-05`（政策权属链条提示）、`DD-06`（商务成数口径提示）四项任意顺序完成后，到达 `DD-07`。

## 路径一：确认（confirm → close）

- `DD-07` 确认：现有记录无误，疑点保留为待澄清项；复核人确认消息入流。不采信任一次陈述。
- 自动接 `DD-08` 尽调汇总：待核实事项清单（时点补证/产能台账/矛盾澄清/设备复检）随单流转，无正式审批结论。
- 签约前 `SG-02` 人工复核再逐项核对后才可进入签约。证据版本不变（M1-DOC-01 仍 v1）。
- 测试：`确认路径` 用例 + `主线全绿走查`。

## 路径二：纠正（correct → close）

- `DD-07` 纠正：更正记录笔误——纪要"**年产值约450万元**"应为"**月产值约450万元**"（溯源 M1 主案例 S4-R2a，合成）。
- 机制效果（模块执行，可测）：
  - 证据升版：`M1-DOC-01 v1 → v2`（更正记录 M1-DOC-07 关联）；v1 状态置 `superseded`，`assertEvidenceCite(state,'M1-DOC-01',1)` 明确返回 `EVIDENCE_VERSION_SUPERSEDED`——**纠正后旧版本不再有效**（历史原文保留可追溯）。
  - 意见作废：`OP-CAP-ENERGY`（基于"年产值"口径的产能-能耗匹配分析）进入 `invalidatedOpinions`。
  - 幂等：同目标版本不重复升版（`退回后纠正` 用例断言版本表仍恰为 v1 superseded + v2 valid）。
- 疑点 DD-DOUBT-1 的"满负荷 vs 一半产能"矛盾不受本更正影响，仍待客观材料澄清。
- 测试：`纠正路径`、`退回后纠正路径证据仍只升版一次`。

## 路径三：退回（return，有限）

- `DD-07` 退回：尽调退回补充，要求客户提供排产/订单/台账记录。
- **立即生效的不全绿**：决定级 viewPatch 使信审判断灯=红（"尽调退回补充中"）、整体注记"未通过"；`DD-08`/`SG-01` 因 `requiresAny` 的 outcome 条件（仅 close 解锁）不可达——**退回后不会带着未处理疑点继续全绿**。
- 补充子路径（尽调阶段内动作，不是额外业务阶段）：
  1. `DD-RT-1`（人工动作）：客户补交材料挂接（M1-DOC-09 排产与订单记录摘录 v1，合成）；
  2. `DD-RT-2`（自动）：系统复核补充材料（仅核对挂接与类目，不核实真伪）；
  3. `DD-07B`（人工决定）：重新判断——机制版仅提供确认/纠正（二次退回被图结构排除，`decide(return)` 返回 `INVALID_DECISION`）；A 形状映射为补证循环，差异见 `candidate/STORY_SCHEMA.md` §3.1。
- 闭环：`DD-07B` 确认/纠正 → `DD-08` 汇总（patch 窗口随 DD-08 完成关闭，红灯解除、保留待核实黄灯）→ 主线继续。重新开始：结清后或任意时刻按演示约定重置（仅重置演示状态）。
- 测试：`退回路径`、`签约退回路径`、`分支无死路`。

## 签约层退回（同一模式，第二处人工门）

`SG-02` 签约前人工复核（依法/制度必需的决定，模型自信不可替代）：
- 确认 → `SG-03` 签约完成；
- 纠正/退回 → `SG-RT` 补充说明 → `SG-02B` 重新复核（机制版仅确认；A 形状 correct→SG-03、return→SG-RT）→ `SG-03`。
- 退回期间信审红灯、注记"签约退回补充中"；自动推进在 `SG-02`/`SG-02B` 均暂停（测试断言 `stoppedAt`）。
