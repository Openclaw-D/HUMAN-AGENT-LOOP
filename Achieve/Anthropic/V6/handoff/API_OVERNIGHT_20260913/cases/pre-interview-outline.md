# 访谈前准备提纲（最简，供 A 路演示复用）

- 适用：M1 及两变体的演示访谈；**全程显著标注"合成演示"**，不冒称真实客户/真实会议。
- 依据：2026-09-13 用户要求（实控人须在经营现场；财务/生产等人员现场或实时入会）；演示中由参与者自报在场方式，**自报 ≠ 核实**（对齐产品 attendance 语义）。

## 一、会前准备（访谈开始前）

1. 参与者与在场方式核对：实控人（经营现场）、财务/生产（现场或实时入会）、我方业务/协调；缺席者如实标注，不模拟在场。
2. 材料预检：按案例 JSON 步骤挂接证据（E1–E3），核对版本与清单所载；缺件如实列示，不预填。
3. 环境核对：会话标题带"合成演示"；模型入口状态可见（real 未配置时显示"未配置"，可切换既有模拟入口）；演示窗口与 D 路 QA 窗口错开。
4. 角色声明：模型输出仅辅助（authority=none），正式意见由人工作出；内部专业建议不对客户展示。

## 二、开场必核（约 2 分钟）

1. 身份与在场：实控人自报姓名/职务/所在场所；财务/生产人员自报在场方式。
2. 知情与边界：说明访谈目的、记录方式与合成演示属性（真实业务中为录音/记录告知，演示中以文字声明代替）。
3. 沟通方式：约定"听不清/需查资料可稍后补充"，补件承诺记为承诺，不当场视为已收到。

## 三、基线必问（信审主问，每题记录：答案原文 + 追问来源）

1. 主体与权属：设备权属人、有无抵押/查封/共有（对 M1：权属链条是政策岗关键补证事项）。
2. 设备明细：型号/序列号/出厂日期与清单是否一致（引导对 E1 页面逐项核对）。
3. 取得时点：购入/签约/付款/到厂各节点年份——**让客户自己展开，不替客户归纳口径**（M1 主线疑点由此暴露）。
4. 产能与能耗：当前开工水平、月产值口径（年/月分开确认）、电费量级（M1 的"年→月"更正与 V2 的"满负荷 vs 一半"均在此暴露）。
5. 设备状况：保养/维修历史（与现场画面观察分开记录，观察只记"拍摄当时可见"）。
6. 资金与回款：拟融资金额用途、租金来源、回款账户。
7. 对外负担：担保、借款、涉诉（合成案例内为"无/未知"时如实记录"未核验"）。

## 四、疑点追问原则（发现疑点时）

- 引用原文与来源："您在 X 时提到……现在提到……"——双侧记录，不当场纠错、不诱导改口。
- 客户解释全 record（claimed），能补凭证的当场约定补件清单与时限。
- 不确定/矛盾 → 列入"待澄清事项"，保持开放；禁止访谈中给倾向性评价。

## 五、收尾（约 2 分钟）

1. 复述补件清单（逐项：材料名+时限）与后续安排；请实控人确认记录要点。
2. 会后 30 分钟内（演示中为演示节奏）：业务补录纪要 → 信审标注发起分析（M1 S2）→ 后续按案例步骤推进。
3. 全程留痕：问答时间点、在场状态变化、模型辅助入口的每次调用在会话记录可回看。
