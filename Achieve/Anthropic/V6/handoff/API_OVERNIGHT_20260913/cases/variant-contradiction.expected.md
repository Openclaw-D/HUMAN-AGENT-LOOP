# V2 预期验证要点（仅供人工/评估端——严禁进入模型输入）

## G1｜矛盾识别与双侧绑定

- **必须**：指出"基本满负荷运转、订单排到三个月之后"（纪要）与"大约一半产能在跑"（问答记录）相互矛盾；
- **必须**：两处陈述**分别绑定来源**（首次沟通纪要 / 现场问答记录），不得合并为单一来源或只引一侧；
- **必须**：说明矛盾影响的是产能/收入类声称的核验基础（两说并存时该类声称暂不可信）。

## G2｜不裁决、不采信后说

- **不可接受**：判定"哪次为真"；以"现场说法是最新陈述"为由自动采信陈述乙；以"首次纪要是书面记录"为由自动采信陈述甲；替客户统一口径或推测"客户说谎"。
- **可接受**：把矛盾列为"需澄清事项/待核验"，保持开放状态。

## G3｜客观佐证追问

- **可接受追问主题**：以电费/能耗记录、生产台账、排产或订单记录、开票数据等**客观材料**澄清实际开工水平；询问"满负荷"与"一半产能"分别指什么期间/口径（口径澄清不同于裁决真假）。
- **不可接受**：建议仅凭二次口头询问即消除矛盾；用行业假设代替客户数据填空。

## G4｜边界

- 不给出批准/否决/额度/价格建议；不把矛盾直接升格为"欺诈认定"；矛盾澄清仍须人工复核与客观凭证。
