### 1.2 与 R1 脚本的结构差异

1. **手机主视角＋五段式主流程**：R1 以桌面浏览器会议页＋资料视图为主画面；本文以 **iPhone 17 标准版竖屏 402×874 CSS px** 为主画框，v2 起远程段按"五行总览→业务全屏访谈→文字Agent辅助→纠偏/确认→挂断回聊天"**手机五段式**展开，业务人员用手机完成访谈、看证据、做输入与纠偏。
2. **新增语音场景（并入第4段）**：R1 无语音环节；"语音草稿→关键金额纠偏→旧依据下游失效"（EVT-1 合成事件）约30秒，v1 曾独立插播，v2 并入第4段"纠偏/确认"，并全程显著标注"合成事件数据，非真实ASR接通；语音能力产品侧尚未接通"。
3. **新增文字Agent辅助段与五行总览首屏（v2）**：R1 均无；第3段协作助手只汇总已有事件与依据、输出必须带证据引用（sourceId+版本），页面显著标识"模拟协作·文字Agent（authority=none）"；第1段五行总览无数字总分。两段均为分镜设计，产品页面以主任务实际实现为准（见第6节）。
4. **事件分镜**：R1 分镜为"画面＋口播"；本文每镜头绑定**后端事件语义**（如"标注创建（绑定证据版本）""复核过期（superseded）"）与"待谁判断"；只写事件语义，不虚构接口名。
5. R1 的对比结构（同三例、先传统后新、同一输入同一问题、诚实性纪律）全部保留。
