## C. 接口边界（语义固定，具体路由由CP0映射）

### C1. 会话与视频adapter

- 现有项目页增加“远程尽调”入口；会议视图建议置于同一app/v5-preview下的子路由，返回后保留项目、情景与草稿。相同会话手机/桌面共享业务状态。
- 对齐projectId、contextVersion、contextGeneration；sessionId稳定关联项目，媒体供应商roomId仅外部引用。重名项目/客户缩写不是主键。
- 服务端选择参与权限；浏览器不能提交更高权限role作为可信身份。客户参会者、我方专业人员、模型角色是不同概念。
- adapter能力建议含读取能力/会话状态、加入、离开、请求清晰采集。定义not_configured、connecting、connected、reconnecting、failed、ended及取消/清理语义；具体接线以CP0状态图为准。
- 当前默认not_configured：页面能进入查看，加入/采集操作说明“视频服务未接入”，不创建摄像头流、不申请权限、不发网络请求、不随机跳connected。
- 测试adapter可显式选择simulation且明显显示“模拟会议”；fixture不可晋升live。真实provider未来通过服务端授权获取短期会话访问能力，凭证不进入源码、URL或日志。
- 拒绝跨项目session访问；旧连接事件不能污染新会话。页面退出清理监听；未来真实接入离会需关闭本地媒体轨道。无真实接入时不得宣称这些设备行为已验收。

### C2. 证据、问题、复核

- Evidence记录：evidenceId、projectId、sessionId、输入版本、采集者或system来源、capturedAt/receivedAt分开、sourceType（simulation / received_video_frame / device_photo等）、原始资源引用、mime/尺寸/hash、verificationStatus。
- 本包只使用明确标识的静态合成fixture，不开放任意URL拉取/文件上传。原件与派生标注分离，客户端字段需要后端验证；hash是完整性线索不是真实性认证。
- Annotation记录：annotationId、evidenceId、归一化圈选坐标、问题文字、服务端确定的作者、版本、状态。缩放和横竖屏不改变圈选所指区域；无证据不能形成悬空标疑。
- Review记录：reviewId、具体证据/问题版本、人工意见、处理动作、审核者来源和时间。证据/问题更新或新争议出现后旧确认过期，不自动继承已核实。
- 所有写请求绑定requestId及expectedVersion，明确冲突与未知；重复请求不重复创建，陈旧回执不清新草稿、不改新会话提示；状态持久化使用既有受控机制并单列能力上限。
- 客户陈述、模型提取、人工核实分开；本人入会和本人确在经营现场的证据也分开，不因视频已连接就显示“现场已认证”。

### C3. 人工监督、阈值与经济性

- RuleConfig契约区分技术质量、证据充分性、业务风险、经济性；至少包含配置版本、来源/确认状态、适用范围、字段及单位、比较方法和触发动作。当前业务阈值为null/unconfigured；不开放自由编辑生产规则的后台。
- 触发动作仅限提示、要求补证/重拍、暂停本轮判断、转人工；不得用模型confidence决定正式放行。未知值不是0，缺配置不是通过。
- Calculation接口包含方案金额/期限/报价、现金流与成本输入引用、计算口径版本、输入digest、状态（not_configured / missing_inputs / ready_for_review / blocked / stale等，CP0冻结）、原因和可选结果。
- **本包不实现未确认的风险定价公式。** 未配置就返回not_configured，展示需要哪些输入；不得靠模型编一个盈利值。计算内核后续必须采用确定性实现并验证单位/期间、折现与成本重复计入；具体门槛由人确认。
- 更充分资料可使风险判断改善或恶化；不得编码“上传数增加→更高额度/更长期限/更低价格”。方案条件改变须重算；负收益方案不推荐，盈利也不覆盖风险缺口。
- 可以用纯合成契约fixture验证负收益、未知、过期等界面/状态门，必须标为“测试输入，非实际核算”。不加可执行的“批准授信/自动报价”按钮。
