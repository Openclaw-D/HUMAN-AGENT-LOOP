# D路 黑盒验收设计与风险清单（V7 backend · 合同未出，Day-1）

制定：2026-09-15。依据：LONG_RUN_GOALS.md §共同/§D + CONTEXT_LOG.md 实验目标。合同（A 的 CONTRACT.md）发布后本文件升级为可执行验收矩阵；在此之前为测试设计与风险登记。

## 0. 边界与手段

- **只写 `V7/backend/D/**`**；A/B/C 与 site/V6/home/** 只读；3607/3467 不碰。
- 故障注入只用**自己的隔离数据目录与服务实例**（`D/runtime/`，端口约定 **3490–3499**，起服务前探测空闲）。
- 所有测试步骤**有界超时**（HTTP 10s、进程操作 30s、E2E 单用例 60s；可配置）；无界重试禁止。同一阻断复测不超过 2 次，无新证据不空转。
- 真实模型调用：D **不做**（无授权凭据）；涉及真实通道的用例标注"凭据阻断"，用 B/C 的真实证据+D 的合成桩覆盖其余。
- 结果四分法：**工程故障 / 模型能力 / 规则缺口 / 数据不足**，每条结论必须归类。

## 2. 黑盒验收矩阵 X（合同发布后逐项映射到真实接口）

| # | 验证项 | 黑盒方法（接口无关） | 通过判据 | 归类 |
| --- | --- | --- | --- | --- |
| X-1 | 双客户端共享事实 | 两个独立 HTTP 客户端（不同"设备标识"，若接口有）对同一 project 读事实；一端写→另一端轮询≤N秒读到同版本 | 两端读回字节级同版本事实；写端回执=读端所见 | 工程 |
| X-2 | 重复/并发提交 | 同 requestId 同载荷重放×2；同 requestId 换载荷；并发 N=4 同 requestId 同载荷 | 重放=replayed 且不重复记账；换载荷=409族；并发=恰好一条生效，其余幂等或冲突 | 工程 |
| X-3 | 重启恢复 | 正常写→SIGKILL 进程→重启→读事实/回执/人工接管状态 | 全部恢复且版本单调；无半写状态被当作完整 | 工程 |
| X-4 | 模型发送后断网 | 隔离实例+可控故障点（代理层断连或进程暂停）：请求已发出→连接中断→系统行为 | 出现 `unknown` 记录+升级人工；**不**自动重试为成功；同输入重放不二次计费记账 | 工程（真实通道部分=凭据阻断，用 B/C 证据） |
| X-5 | 证据替换→旧意见过期 | 写证据 v1→产生模型意见（引用v1）→替换/更正为 v2→读旧意见状态 | 旧意见标 stale/待复核或引用被拒；不得仍作为现值通过 | 工程+规则 |
| X-6 | 计算工具单位/缺参/公式版本 | 调计算工具：正常输入；缺输入；口径矛盾；单位不一致 | 正常=带单位+假设+公式版本的确定性结果；缺参=明确拒绝**不补造**；公式版本可追溯 | 工程 |
| X-7 | 伪造引用 | 构造引用不存在证据ID/公式版本的模型候选意见提交 | 被检出/拒绝或标注不可信；不得静默入库为有效引用 | 规则+工程 |
| X-8 | 越权人工动作 | 用模型意见直发"正式动作"；无身份凭证调用人工接口；旧版本号提交 | 全部被拒（403/409族）；模型意见永不直接成为正式动作 | 工程 |
| X-9 | 错误不伪装成功 | 全部故障路径（X-3~X-8 触发的失败）检查 HTTP 状态+响应体+落库状态 | 失败=非2xx或显式 error 字段+无虚假 success 落库；unknown≠failed≠success 三态可辨 | 工程 |
