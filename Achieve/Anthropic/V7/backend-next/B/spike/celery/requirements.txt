# V7 backend-next B · Celery 隔离技术 spike(有界)
# 任务书边界:Celery 只负责任务投递/领取重试(投递层);Agent 节点执行归 LangGraph(B worker);
# 业务状态唯一权威是 A(PostgreSQL)。Celery 不掌握业务状态、不盲重试 LLM:
#   - 投递任务只携带 goalId + executor URL,不携带业务数据;
#   - 重试只是"再次通知执行器",执行器侧以 claim/fencing/回执判幂等(目标已不可领 → no-op);
#   - retries 有界(max_retries=3,指数退避),acks_late 保证 worker 崩溃重投。
# 锁版来源:PyPI(celery 5.4.0 / redis 5.0.8;Celery 5.x 官方支持 Python 3.11 与 Redis broker)。
