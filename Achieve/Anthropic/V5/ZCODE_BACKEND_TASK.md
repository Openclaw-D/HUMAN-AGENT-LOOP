## B0｜立即执行：可复用后端与接续契约

单一目标：交付可审查的最小后端接续设计，指出哪些可以复用、哪些缺失，并提供当前复验结果。

允许写入仅限：

- V5/backend/B0_REPORT.md：状态、实测、差距、未决项与停止点。
- V5/backend/B0_INTERFACE_CANDIDATE.md：拟议消息、上下文、状态机、API、ownership 和适配设计。
- V5/backend/B0_BASELINE_MANIFEST.md：拟基线文件分类、用户改动归属待确认项、非Git数据边界、恢复方案；只列清单，不 commit/tag。
- V5/backend/evidence/B0/**：脱敏测试输出、来源索引、合成示例消息与事件轨迹。不得放凭据或真实业务数据。

步骤：

1. 精确核对上述模块，形成“当前能力→缺口→最小改动→验证”矩阵，不宽扫归档或平台历史。
2. 使用已安装依赖运行 npm.cmd test、npm.cmd run typecheck、npm.cmd run lint、npm.cmd run build；检查 HTTP quality 脚本运行方式后执行进程内检查。捕获真实退出码和输出，不隐藏失败，不顺手修复。构建器正常生成的忽略目录可产生；若检查修改受控文件，报告差异，不自动还原。
3. 从 A2A 官方规范/项目及 Microsoft 官方 Agent 协作资料核验与本任务直接相关的能力：任务身份、消息往返、状态/取消/订阅、人输入与恢复支持。报告读取日期、版本/来源链接，明确标准原生支持、框架能力与需应用层实现三者。只读公开资料；网络失败标记未核验，不凭记忆声称最新。不得引入 SDK 或安装依赖。
4. 设计一个合成事件：业务协调 Agent 形成四份有共同事实引用、不同职责和任务输入的 packet；四域可往返回复；人纠偏后受影响任务按新版本继续。无需实现业务模型，不改四域制度规则。
5. 为 B1 提出精确新增文件和必要现有文件修改清单、共享类型唯一 writer 与 API 兼容策略。优先沿用现有运行时与事件/命令验证能力，避免独立新事实源或第二套权威状态。

建议的接口讨论内容（工程 Candidate，不能当成已接受 schema）：

- 消息身份及关联：case/event、message/task、sender/recipient、关联链及回复对象。
- 输入与上下文：版本、证据引用、域职责、任务目标、允许动作、依赖和输出约束；共用事实保持一致，按职责挑选相关内容，不靠给相同提示词换角色名冒充差异化。
- 状态与触发：可派发不等于可正式推进；等待、运行、待人、暂停、候选完成与正式决定分开。
- 纠偏：记录具名人的纠正内容及适用范围；计算受影响任务，拦截旧版本晚到结果进入当前有效上下文，保留原始证据及历史。
- 重试与恢复：重复/乱序消息、超时、取消后晚到、重启后恢复；说明当前单进程边界，不能承诺分布式 exactly-once。
- 上下文重建：从有来源、版本的持久记录恢复；summary 只作索引/辅助。compact 后不凭丢失的聊天记录猜测事实。
- 写入权：Agent 只提交结果建议；共享对象由现有受控服务命令验证并写入。并行候选按版本检测冲突，不由业务 Agent 冒充审批人决定。
- 可视投影：总进度、四域状态、阻塞原因、下一行动者和动作、版本与更新时间；先定义服务端语义，不做拼图页面。

风险平衡待 Control 评审：只对明确无硬前序、低成本可撤回的任务允许准备性并行；不为演示新造政策阈值，不静默替用户决定重要并行边界。

B1 必须覆盖的行为测试：

1. 同一事件的四个 packet 共享同版本事实引用，职责/目标/相关输入存在有意义差异。
2. 无硬依赖的准备任务可同时就绪；正式前序未完成时拦截推进。
3. 任务派发后能关联回复与追问，重复消息不重复产生工作或结果。
4. 人工纠偏形成新版本；受影响任务停止旧推进，未受影响工作保留；旧结果晚到被隔离且可追溯。
5. Agent 不能伪装成人批准/否决、创建正式 Receipt 或修改正式核验事实。
6. 共享对象同时提交触发可解释冲突，不静默覆盖。
7. 从隔离持久化数据重新启动后，可重建当前任务、纠偏依据、依赖与可见历史；缺记录或损坏时明确失败关闭。
8. 取消、超时、重试失败有边界，不无限自派工或无限增长上下文。
9. 投影能解释谁在做、等什么、需要谁接手；Agent完成与人工批准不混同。

验证须包含真实 HTTP 边界测试、相称回归及 test/typecheck/lint/build，记录环境与限制。若需服务，只能在任务明确放行后使用自身隔离 loopback 端口和合成目录，不能碰现有3100/3101服务或共享日志。产品视觉、生产认证、真实模型、跨框架互通与收益评估为后续 Gate。
