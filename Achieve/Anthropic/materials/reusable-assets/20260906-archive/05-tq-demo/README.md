# TIANQU 天驱

面向融资租赁场景的 Agent 协作展示原型。首页用一条从上到下的主线展示：

任务进入 → 调度拆解 → 并行取证 → 事实汇合 → 并行判断 → 人工闸门 → 执行交付 → 底层能力沉淀

路由、并行、重试、异常演示、Agent 责任和交接规则统一放在齿轮设置页，避免干扰主画面。

## 运行

直接双击 **index.html**，使用现代 Chrome 或 Edge 打开；也可以在本目录运行：

    python -m http.server 41732 --bind 127.0.0.1

然后访问 http://127.0.0.1:41732/。

无需安装依赖，不调用外部接口，不读取真实客户或业务数据。

## 交互

- 点击“开始演示”，观察 Agent 按依赖顺序运行。
- 材料与客户、政策与风控默认并行。
- 流程到达人工闸门时暂停，点击“人工确认并继续”后完成交付。
- 点击 Agent 可查看其输入、输出、责任人和权限边界。
- 点击齿轮可调整协作策略、演示证据冲突或预览页面状态。
- 底部“运行记录”默认折叠，只保留关键交接。

演示项目 TQ-2027-001 及页面中的材料、数字和状态均为虚构、脱敏数据，不代表真实客户或审批结论。

## 文件

- **index.html**：纵向主画面和设置页面。
- **styles.css**：视觉、状态和响应式布局。
- **app.js**：运行模拟、并行协作、异常重试与人工闸门。
