# P1 中国 AI 岗位市场重研契约

日期：2026-08-27  
状态：本轮执行契约

## 目标

用公开、无需登录的 Web Search 结果建立约 1,000 条中国市场 AI 岗位候选池，先排除已确定的三个优先场景，再用市场证据重新定位其余七个候选场景。旧 91 条证据库只作为种子与交叉核验材料，不决定新排序。

目标数量为 900–1,100 条去重后的候选记录。候选池用于覆盖度，不等同于 900–1,100 条已核验在招岗位。

## 已排除的三个场景

以下场景不参与“剩余七项”的排名，但相关岗位仍可留在原始候选池，用于统计排除量：

1. 业务风控与具名人工决策；
2. 需求—开发—测试—发布协作；
3. 通用 Agent—Agent—Human 多方协作与 Harness。

## 公开检索边界

- 只使用后端 Web Search 与无需登录即可读取的公开页面。
- 不使用 `computer use`、Chrome、浏览器登录态、验证码绕过或账号会话。
- BOSS、智联、LinkedIn 等页面一旦要求登录、安全校验或验证码，保留公开搜索摘要并降级，不进入“已核验详情”口径。
- 不把搜索摘要、聚合页或共享列表页伪装成可直接读取的岗位详情。
- 不发明岗位 ID、公司、原标题、城市、薪资、发布时间或 URL。

## 覆盖结构

### 公司组

至少覆盖 30 家中国市场相关企业，包含：

- 大型平台：字节跳动、腾讯、阿里巴巴、京东、美团、百度、快手、滴滴、拼多多、携程、网易、蚂蚁集团；
- 终端与汽车：华为、小米、OPPO、vivo、联想、蔚来、小鹏、理想、比亚迪；
- 基础模型与 AI Native：智谱 AI、月之暗面、MiniMax、DeepSeek、阶跃星辰、百川智能、商汤、科大讯飞、第四范式；
- 企业软件与产业科技：金山办公、用友、金蝶、海康威视、顺丰、菜鸟及公开结果中出现的高薪企业。

### 来源组

- 官方招聘/官方职位详情目标占清洗后证据的 55%–70%；
- BOSS、智联、LinkedIn 等公开搜索摘要目标占 30%–45%；
- 任一来源不得超过清洗后候选池的 35%；
- 不能直接访问详情的记录单独标记 `search_snippet_only`。

### 检索关键词组

每家公司按适用性组合检索：`AI`、`人工智能`、`大模型`、`LLM`、`Agent`、`智能体`、`多模态`、`AIGC`、`RAG`、`MCP`、`A2A`、`AI Infra`、`推理`、`评测`、`安全`、`具身智能`、`AI 产品经理`、`AI 平台`、`AI 应用`。

## 候选记录字段

原始 Web Search 结果写入 JSONL，每行必须包含：

```json
{
  "query_id": "Q0001",
  "query": "原始检索式",
  "result_rank": 1,
  "title": "搜索结果原标题",
  "url": "https://...",
  "snippet": "公开搜索摘要",
  "captured_at": "2026-08-27",
  "source_platform": "official|boss|zhaopin|linkedin|other",
  "company_query": "检索时指定的公司或公司组",
  "keyword_group": "agent|llm|multimodal|infra|product|application|governance|embodied|other"
}
```

规范化输出必须补充：`candidate_id`、`canonical_url`、`domain`、`job_or_page`、`access_class`、`dedupe_key`、`salary_text`、`annual_min_k`、`annual_max_k`、`high_salary_signal`、`freshness_text`、`top3_exclusion`、`theme_labels`、`evidence_grade`、`drop_reason`。

## 薪资口径

- 只有公开文本明确给出薪资区间和月数时才计算年薪；不假设 13 薪、14 薪或奖金。
- `high_salary_signal=confirmed_floor`：可计算年薪下限至少 400K。
- `high_salary_signal=possible_ceiling`：可计算年薪上限至少 500K，但下限不足 400K。
- 只有月薪、没有明确月数时标记 `monthly_only`，不得转换成年薪。
- 搜索摘要中的高薪只能作为候选信号，不能声称实际 offer 或市场均值。

## 去重与证据等级

去重优先级：规范 URL/岗位 ID → 公司 + 原标题 + 城市 → 公司 + 原标题 + 来源平台。共享搜索页不能据此制造多条岗位。

- A：无需登录且本轮可读的官方岗位详情；
- B：官方岗位索引或官方招聘页能唯一识别岗位；
- C：公开招聘平台搜索摘要能识别标题、公司和 URL/页面；
- D：无法唯一识别、关键词噪声、重复、仅培训/资讯内容；D 不进入有效候选池。

## 七场景重排

先从清洗后的非前三记录中聚类，再命名场景，不强行沿用旧十场景标签。每个候选场景按以下维度评分：

1. 有效岗位量与占比：25%；
2. 企业覆盖广度：15%；
3. 高薪信号：15%；
4. 近 180 天或可确认当前性的证据：10%；
5. 前沿 AI 技术密度：15%；
6. 跨人、Agent、系统的工作流价值：10%；
7. 与已排除前三场景的差异度及平台适配度：10%。

最终七项必须逐项给出：样本量、公司数、来源结构、高薪记录数、代表岗位、为何不是前三的重复表达、事实/推断/假设边界和置信度。

## 验收

- 900–1,100 条去重候选；原始数、重复数、D 级剔除数、有效数可复算。
- 至少 30 家企业；至少 3 类来源；公开平台摘要与官方详情分开统计。
- 所有有效记录有原标题、URL、来源、检索式和抓取日期。
- 薪资计算无默认月数；400K/500K 阈值可由字段复算。
- 三个已选场景明确排除；七项由数据重排，不由旧提示词直接指定。
- 报告中的数量、表格和排序全部由规范化数据生成或可复算。
