# P1-01 证据登记说明

日期：2026-08-27  
范围：仅用于“见微-人机协同平台”十场景市场、流程、责任与风险建模。

结构化登记见 [EVIDENCE_REGISTER.csv](EVIDENCE_REGISTER.csv)。每条事实性主张在本目录交付物中使用稳定 `evidence_id` 回指该表。

## 等级

- `A`：法律、监管规章、政府/研究院正式指引或标准；本轮可读取正文，能直接揭示角色、责任、流程或风险结构。
- `B`：企业官网、官方产品文档、官方技术案例、官方岗位或已有本地核验报告；属于一手发布，但产品/效果可能带有自报偏差。
- `C`：仅搜索摘要、索引、二手媒体或无法唯一识别的材料。本轮最终登记没有让 C 级材料承担场景成立或命名冻结的关键结论。

等级只表示来源形态与可核验性，不表示声明一定为真。企业自报指标一律保留“未独立审计”的限制。

## 使用规则

1. 法律/监管材料用来冻结责任、禁止项、必须留痕与负向路径，不外推企业内部产品形态。
2. 企业案例/产品文档用来识别真实工作流对象、系统连接、协同断点与可观测指标，不把供应商功能清单当成市场普遍采用率。
3. 官方岗位只证明投入方向与能力组合，不独立证明完整流程、预算、组织规模或生产效果。
4. `MKT-001` 与 `MKT-002` 是可复算的本地派生证据；其候选数量用于比较市场信号，不冒充逐页确认仍在招聘的岗位数。
5. 同一 URL 被多个场景使用时，仍只登记一次；场景文件必须引用同一 ID。
