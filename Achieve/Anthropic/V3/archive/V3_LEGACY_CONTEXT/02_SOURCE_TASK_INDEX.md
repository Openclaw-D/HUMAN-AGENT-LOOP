- 净利润、设备锚点、三类经营路径、领导 KPI 驾驶舱。

### B. 进入组织与路由 Context

- 集团 / 租赁公司 / 事业部层级；

- 六维证据评审；

- 规则命中、事实核验、评审影响记录；

### D. 只进入演示与视觉参考

- TQ 大拓扑和领导一屏看懂原则；

- Race 五页叙事、黑白灰和 3–5 秒读懂原则；
- Unity / 战局 / 机甲等开场隐喻。

### E. 明确不继承

- 被后续用户纠正的旧方向；
- 旧版硬编码账号、mock 数据权威与单项目状态；
- 未验证的 KPI、模型准确率或生产成效；
- 旧详细流程名、旧技术栈事实和运行 PID；
- 任意会制造第二份 Case 真相的前端状态或组织对象。
