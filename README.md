# 见微 · V0.3

制造业小微客户的材料、AI辅助分析与人工决策工作台。模型没有审批或资金操作权；候选支持评分不等于事件概率。

| 目录 | 内容 |
|---|---|
| [Front](Front/) | 前端源码、构建产物及双击预览入口 |
| [Back](Back/) | 业务内核、材料连接器、模型编排、API与测试 |
| [docs](docs/README.md) | 当前约定、V0.3交付、合成材料与展示文件 |

只看页面：安装 Node.js 22 后双击 **Front/Start-JW.cmd**。这是静态预览，不代表后端已连接。

运行真实后端：按 [Back/START.md](Back/START.md) 配置 PostgreSQL、身份与服务。凭据、数据库、费用账本及运行目录不进入Git；真实模型需自行配置已授权账户，不自动发送调用。

V0.3保留工作台、材料清单、决策树、时间轴四个独立页面。上传授权恢复装配、指定材料组合分析、贝叶斯概率计算及完整业务生命周期仍有未完成项，详见[发布记录](docs/v0.3/RELEASE_V0.3.md)。真实模型历史调用与本地替身测试分别留证。

长期目标和评分见[V0.3基线](docs/v0.3/00_AUTHORITY.md)，不以局部实现冒充全部完成。旧版历史已从当前目录移除，可从Git历史恢复。V0.4继续节点导航、跨页面事件同步与接口质量改进。
