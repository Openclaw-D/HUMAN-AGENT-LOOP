# 见微 · V0.6.0

制造业小微客户的五区协作工作台。当前版本使用十个好／中／差合成案例，真实执行材料登记、规则分析、人工确认、重评和周期状态转换；不是生产审批系统。

页面面向 PC，主要验收尺寸 1920×1080，兼顾较小桌面窗口，不考虑手机。平台、材料、决策、流程读取同一客户状态；短导航、线性专业图标、状态/下一步和金额卡片代替重复长文，详情按需展开。主流程保留一个状态驱动的操作按钮，其他入口集中在“更多”。

V0.6.0 修正原件布尔值与租金单位、解析材料依赖、搁置后重算、语义请求并发去重及过期回执，并在五区结果提交后并发提供只读语义核验建议。已用批准的合成原件实际调用官方 DeepSeek/deepseek-flash；本次测试统计和实际边界见 [API 修复验收](docs/evals/API_REPAIR_20261005_ACCEPTANCE.md)。模型建议不构成人工采纳、授信或审批；合成回归通过不代表所有客户、生产权限或未决业务制度已经验收。

## 本地运行

需要 Node.js 22、Docker Desktop。依次在 Front、Back/A、Back/B、Back/C、Back/Connectors 执行 npm ci，安装各模块锁定依赖；Edge 无额外 npm 依赖。运行目录与依赖不入 Git。

首次配置：在仓库根目录执行 powershell -NoProfile -ExecutionPolicy Bypass -File Setup-JW-Demo.ps1。它将公开合成演示模板写入 Git 排除的运行目录，已有配置不会覆盖。这些演示身份只供本机使用。

双击根目录 Start-JW.cmd，或执行 powershell -NoProfile -ExecutionPolicy Bypass -File Start-JW.ps1。默认页面 http://127.0.0.1:48431/。健康服务直接复用；可核实属于本栈的缺失服务恢复；未知端口占用会停止并报告。-Status 查看真实就绪，-Stop 停本栈并保留数据。

## 怎么演示

1. 首屏选“协作评审 · 查看五区进度”，使用既有五专业授权演示身份；普通专业角色仍按自身权限操作。
2. 横向目录从差到好排列十个案例，卡片解释当前阶段与下一动作，材料包在 docs/integration/2026-09-30-final/materials。
3. 点击五区标题选择专业，点击格子查看材料或人工核验；顶部主按钮提交分析、补件或确认当前意见。确认一次可以触发多个已具备条件的步骤，缺件、硬阻断及后续人工确认不会自动跳过。
4. “更多”集中需求与申请、待办、履约结清返单、建议方案和预评估确认。返单先完成新一轮五区评审，再继续返单创建独立周期。
5. 右侧助手绑定当前客户和专业，直接输入问题即可，@ 可选。未配置真实模型时回答明确标注为确定性案例说明，不能代替人工确认。

案例 01 收入红线；02 权属阻断；03 偿债风险；04 现金流补件；05 金额冲突；06 三项事实核验；07 新证据重评；08 预评估确认；09 回执与结清；10 独立返单。

模拟的是客户、材料与外部事件；服务端权限、版本、幂等请求、事件记录和状态转换实际执行。预评估确认不批准正式额度；外部收付款未连接，回执明确标为模拟。本轮真实模型验收限于三例批准合成原件的已知回归；生产身份、盲测泛化和长期可用性未验收，不以技术测试代替用户视觉或生产验收。
